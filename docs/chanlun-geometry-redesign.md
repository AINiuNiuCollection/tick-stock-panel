## 0. 结论先行

现有实现工程质量扎实（adapter 隔离原生对象、缓存、SSE、不可变快照都正确），但**理论口径与缠师严格定义存在系统性偏差**。经 108 课原文核对 + 真实数据实证（贵州茅台 600519.SH，1495 根日线），确认：

| 类别 | 问题 | 实证 |
|---|---|---|
| 确凿缺陷 | 趋势判据缺失"中枢不重叠" | 3 只股票 15 次趋势背驰判定，计入的中枢 **100% 存在价格重叠**，系统性违反缠师第18课 |
| 确凿缺陷 | B2/S2 次级别验证空转 | 注入永远返回 False 的验证器，S2 仍输出 |
| 级别错位 | 用"笔"代替"次级别走势类型"构造中枢 | 24 个中枢全部由笔重叠而来 |
| 口径偏离 | B3/S3 强加背驰前提、背驰 AND 化、无区间套 | 见 §3 |

本设计的立场：**缠师本人若实现，会从"级别递归 + 几何唯一性"出发，先定义最底层的分型/笔/线段，再逐级递归出中枢与走势类型，买卖点只是递归结构的必然推论**——而不是像现状那样，在"笔"这一层直接套用中枢公式和买卖点模板。

## 1. 缠师算法观（原文锚点）

### 1.1 三层递归结构（第65课）

原文第65课给出严格几何定义，顺序不可逆：

1. **分型**：相邻 K 线包含关系按"顺序原则"合并（第65课："先用第1、2根确认新K线，再用新的与第3根比"——即 while 传播，非 if）。答案"唯一、客观、与时间与人无关"。
2. **笔**：一顶一底交替，"所有图形都可以唯一地分解为上下交替的笔的连接"。
3. **线段**：至少三笔，**前三笔必须有重叠**；"线段破坏的充要条件，就是被另一个线段破坏"。
4. 再往上才是中枢与走势类型。

**关键推论**：缠师的中枢输入是"次级别走势类型"，而不是"笔"。原文第17课："某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分，称为缠中说禅走势中枢。"第18课重申："次级别的前三个走势类型都是完成的才构成该级别的缠中说禅走势中枢。"

> 现状偏离：`zs.py::build_zs_strict(bi_list)` 直接以笔为输入。这跳过了"线段/次级别走势类型"层，导致整个级别体系下移一档。这是**工程妥协**（czsc 库亦如此），但必须正名：当前输出是"笔级中枢"，不是缠师定义的严格级别中枢。

### 1.2 中枢的严格公式（第18、20课）

第18课原始公式：三段 A/B/C 高低点 `a1/a2, b1/b2, c1/c2`，中枢区间 = `[max(a2,b2,c2), min(a1,b1,c1)]`。

第20课进一步严格化（Z 走势段口径）：与中枢方向一致的段记为 `Zn`，高低 `gn/dn`；`GG=max(gn), DD=min(dn)`；**`ZG=min(g1,g2), ZD=max(d1,d2)`**，`[ZD,ZG]` 即中枢区间。并给出中枢中心定理一："中枢的延伸等价于任意区间 `[dn,gn]` 与 `[ZD,ZG]` 有重叠"。

> 现状：`make_zs()` 用前三笔的 `[max(low), min(high)]`——符合第18课原始公式，但**未采用第20课的 Z 段严格化**（ZG/ZD 只用前两个同向段）。这是可接受的近似，但应在文档中标注口径。

### 1.3 趋势判据：绝对不重叠（第17、18、20课）

- 第17课："趋势：至少包含两个以上**依次同向**的缠中说禅走势中枢。"
- 第18课（决定性）："注意，趋势中的缠中说禅走势中枢之间**必须绝对不存在重叠**。"
- 第20课（强化）："同级别的前后缠中说禅走势中枢是不能有任何重叠的，**这包括任何围绕走势中枢产生的任何瞬间波动之间的重叠**。"

**禅师实现观**：判定趋势时，必须维护一个"已确认中枢序列"，新中枢若与前一个中枢的波动区间 `[DD,GG]` 有交集，则不是趋势的新中枢，而是**中枢扩展/更大级别盘整**（第20课级别延续定理二："更大级别中枢产生，当且仅当围绕连续两个同级别中枢产生的波动区间产生重叠"）。这个判定必须在背驰之前完成——因为"没有趋势，没有背驰"（第15课标题）。

### 1.4 三类买卖点的严格定义

| 类型 | 原文定义 | 关键约束 |
|---|---|---|
| 一买 | 第17课：下跌走势完成的关节点；第27课："第一类买点肯定是趋势背驰构成的" | 必须在下跌趋势最后一个中枢下方，趋势背驰 |
| 二买 | 第17课："第一类买点出现后第一次次级别回调制造的低点"；买卖点定律一："任何级别的第二类买卖点都由次级别相应走势的第一类买点构成" | 不破一买低点 + **次级别一买确认** |
| 三买 | 第20课定理："一个次级别走势类型向上离开中枢，然后以一个次级别走势类型回试，其低点不跌破 ZG，则构成第三类买点" | **唯一约束是位置**（回试不回中枢），缠师未要求背驰 |

第21课补充：中枢三态（延续/扩张/新生）决定买卖点归属——三买是"中枢扩张或新生产生的"；二买"不必然出现在中枢的上或下，可以在任何位置"。

### 1.5 背驰的严格口径（第15、24、27、37课）

- 第15课："没有趋势，没有背驰。在盘整中是无所谓背驰的。"
- 第24课：用 MACD 判断的前提是 A/B/C 三段处于大趋势，B 是中枢且黄白线回拉 0 轴，C 段 MACD 柱面积 < A 段。缠师明确这是"辅助判断"，"要精确地判断背驰，还是要从中枢本身出发"。
- 第37课：a+A+b+B+c 中，A/B 必须是同级别中枢，c 必须创新高/新低，"c 必然是次级别的，至少包含对 B 的一个第三类买卖点"。
- 第27课：盘整背驰"只要其中一个符合就可以是一个背弛的信号，两个都满足就更标准了"——**面积与黄白线是"或"关系，非强制 AND**。

## 2. 缺陷根因：级别视角

两处确凿缺陷表面看是 `count_zs_in_trend` 漏检查和返回值丢弃，深层是同一个根因：**实现把"买卖点识别"建立在未经级别验证的结构之上**。

```
现状流水线（错误）：
  笔 → [直接套中枢公式] → 伪中枢(大量重叠) → [只数方向] → 伪趋势 → 趋势背驰 → B1/S1
                                            → [次级别验证空转] → B2/S2
```

缠师要求的流水线：

```
正确流水线：
  分型 → 笔 → 线段(三笔重叠, 线段破坏) → 次级别走势类型
     → 中枢(三个连续次级别走势类型重叠, ZG/ZD用Z段)
     → 中枢序列 + 重叠判定 → 走势类型(盘整/趋势: 同向不重叠)
     → 只有确认趋势才做趋势背驰; 盘整只做盘整背驰
     → 买卖点是上述结构的推论, 三买只凭位置, 二买必须次级别一买确认
```

**根因**：`domain/` 层没有"走势类型"这个一级抽象。中枢序列之间没有状态机（延伸/新生/扩展/趋势），`count_zs_in_trend` 用一个行数目的函数代替了走势类型判定。这是最需要重构的地方。

## 3. 优化设计

### 3.1 领域模型新增

```python
# domain/models.py 新增
@dataclass(frozen=True)
class TrendSegment:
    """走势类型：盘整 / 上涨 / 下跌。缠师第17课"""
    kind: str            # "consolidation" | "uptrend" | "downtrend"
    zs_indices: tuple[int, ...]   # 包含的中枢下标
    sdt, edt: datetime

class ZsState(Enum):
    EXTENSION = "extension"   # 延伸：新波动仍触及中枢
    EXPANSION = "expansion"   # 扩展：波动区间与旧中枢重叠 -> 更大级别中枢
    BIRTH = "birth"           # 新生：与旧中枢完全不触碰 -> 趋势延续
```

### 3.2 中枢序列状态机（替代 build_zs_strict 的裸循环）

```
输入：次级别走势类型序列 segs（当前工程退化为 bis，标注为笔级口径）
for 每个候选中枢:
  用第20课 Z 段口径算 ZD/ZG/GG/DD（ZG=min(g1,g2), ZD=max(d1,d2)）
  与前一个中枢比较波动区间:
    重叠  -> 标记 EXPANSION，合并为更大级别中枢（不产生新趋势中枢）
    不重叠且同向 -> 标记 BIRTH，追加到"同向中枢序列"
    触及原中枢 -> EXTENSION，延长原中枢（更新 GG/DD）
  产出带 state 的中枢序列 + 走势类型序列
```

#### 3.2.1 已落地：中枢终止只有一条路径（`zs.py::build_zs_strict`）

**唯一终止条件 = 定理三破坏**，不含"时间到""段数到""简单重叠"这类人为切法。

1. 先判"潜在离开段"——只看笔在**本方向上的终点**是否越出中枢（向上笔 `high > ZG` /
   向下笔 `low < ZD`）。反向极值越界不算离开：盘整内向上笔的低点本来就在中枢下方。
2. 再让**下一笔**做回抽确认：重新回到 `[ZD,ZG]` 内 → 定理二，中枢未破坏，该笔并入
   延伸（只更新 `GG/DD`）；不再回到中枢 → 破坏成立，该笔是真离开段，**不并入**中枢，
   前中枢就此终止，新中枢从回抽笔起重新扫描。

扩展/升级的"波动区间重叠"判据不在 `build_zs_strict` 内做，仍由下游
`zs_ranges_overlap()` / `count_independent_zs()` 统一处理（级别延续定理二）。

**已删除的两条错误路径（保留证据，勿再引入）**

- **路径 A · 任一端点越界即断**（`bi.high > zg or bi.low < zd`）：日线样本 100%、
  30 分钟 92% 的中枢切断属于"部分穿越"（笔的区间仍与 `[ZD,ZG]` 相交，根本不存在
  离开段），等于靠"第 4 笔戳破一边"切中枢。后果：分众 30 分钟 100 笔切出 26 个中枢，
  平均不足 4 笔，三类买卖点随之虚增。
- **路径 B · 九段封顶**（`MAX_ZS_BIS = 8`，出自第33课"延伸不超过 5 段"，第38课同级别
  分解，第59课"延伸 9 段成为 5 分钟中枢"）：第 9 笔强行切出新中枢。实测该规则会
  **制造结构**——分众 30 分钟 2025-11～2026-11 样本中，一个仍在延伸的中枢被切在
  2026-08-19，后半段独立成另一个中枢；两个中枢高低不重叠 → 被下游判成"两中枢下跌
  趋势" → 在一段下跌的两个子段之间做 a/c 背驰比较，在 `2026-08-31 @4.81` 判出伪一买。
  去掉封顶后中枢数 13 → 11，该伪一买消失。
  第33课的"5 段"是**消除分解多义性**的口径（同一图形有多种合法分解时择一），不是
  走势本身的终止条件；定理三把破坏定义为**充要条件**，第20课亦明言中枢"可以不断
  延伸下去直到无穷"。

对应回归测试：`test_zs_extension_has_no_segment_cap`（12 笔全程在 `[ZD,ZG]` 内震荡 →
必须只有一个中枢，`len(zs.bis) == len(bis)`）、`test_zs_does_not_cut_on_partial_crossing`、
`test_zs_terminates_on_third_point_destruction`、`test_zs_extends_when_pullback_returns_into_center`。

#### 3.2.2 「震荡 → 翻倍拉升 → 回落 → 再震荡」为什么不是按涨幅切中枢

用户常问：拉升前后各震荡两个月，涨幅翻倍，是否自动属于两个中枢？**不是**。
缠师不以时间长度或涨幅大小切中枢，唯一判据还是定理三。两种情形的合成实测：

| 情形 | 原中枢 `[ZD,ZG]=[10,11]` 的后续 | 判定 | 输出 |
|---|---|---|---|
| 拉升笔高 24，回抽笔低 15（>ZG） | 回抽不回箱体 | 定理三破坏；离开段不并入 | 两个中枢：`[10,11]` + `[16,18]`，`DD2=15 > GG1=12` → 新生（上涨） |
| 拉升笔高 24，回抽笔低 11（≤ZG） | 回抽跌回箱体 | 定理二延伸；`ZD/ZG` 固定 | 仍一个中枢：`[10,11]`，只把 `GG` 更新为 24 |

关键点：**中枢区间由前三笔确定后不随后续波动扩张**——翻倍拉升只进 `GG`，不能把
`ZG` 拖上去；否则原箱体被"吞掉"，后续所有三买/趋势判断全部失真。拉升后的第一次
回抽若不回 `[ZD,ZG]` 且低点 > ZG，本身即第三类买点（第20课：只凭位置）。

破坏后两中枢的关系按级别延续定理二/第20课处理：波动区间 `[DD,GG]` 完全不重叠 →
新生（趋势的方向基础）；有交集 → 扩展为更高级别盘整，**不是**趋势。

回归测试：`test_zs_rally_then_new_box_forms_two_centers_when_pullback_stays_above_zg`、
`test_zs_rally_then_pullback_into_box_remains_one_center`。

**极端尖刺（直线拉升 100% 后回原箱体）**：仍按定理二判为**同一个中枢的延伸**，不产生
新中枢——尖刺那一进一出两笔并入中枢 `bis`，高点只进 `GG`，`ZD/ZG` 锁死不动（实测：
原 `[10,11]`，拉升高 22 → `GG=22`、`ZD/ZG=[10,11]`、5 笔）。它**不是三买**（三买要求
回抽低点不跌回 `[ZD,ZG]`），也**不构成趋势**（仍是一个中枢 = 盘整）。

**尖刺的连带风险（strict 口径的固有边界，已实测）**：尖刺把 `GG` 从 12 抬到 22 后，
strict 模式用 `[DD,GG]` 判两中枢重叠——后续在原中枢上方 `[13,14]` 形成的新中枢，核心
区间明明与 `[10,11]` 完全不重叠，却因 `[9,22]` 与 `[13,14]` 相交被判"扩展"，上涨趋势链
从 2 断成 1。这是第20课波动区间口径在笔级近似下的固有边界，不是实现错误；用户请求
默认 `practical`（`[ZD,ZG]`）不受影响，切 strict 时须知晓此边界。回归测试
`test_zs_spike_into_box_is_extension_not_new_center` /
`test_zs_spike_gg_can_break_strict_overlap_but_not_practical`。

**实现边界（诚实标注）**：本工程以**笔**近似"次级别走势类型"，故"离开段"是一根笔的
终点越界、下一根笔不回箱体即确认；严格缠论要求离开段本身是完整的次级别走势类型
（至少 3 笔的段）。笔级近似在急涨急跌中可能比严格口径更早确认破坏，该项属于已知
近似，不是定理三的偏离。

### 3.3 买卖点识别修正

- **B1/S1**：趋势背驰前，先断言 `trend.kind in ("uptrend","downtrend")` 且同向中枢 ≥2 且**两两不重叠**（第18课）。不满足则降级为盘整背驰，不输出 B1/S1。
  - 修复 `count_zs_in_trend` → 新增 `build_trend_type(zss)` 返回走势类型对象。
  - **趋势方向判据（`zs.trend_zs_chain`）**：不得用 `Zs.direction`。该字段是
    `models.py` 里的 `self.bis[0].direction`，即"构成中枢的第一笔的方向"，由中枢从哪
    一笔起算决定，与走势方向无关。一段下跌里中枢常常"反弹笔先起"，于是被标成 `up`，
    再被 `direction == "down"` 整体剔除 —— 真实下跌趋势被数成 0 个。
    实测分众 30 分钟 2026-07-16~10-22：ZS8 `[4.9778,5.0669]` → ZS9 `[4.8096,4.9481]`
    → ZS10 `[4.64,4.79]` 三个中枢依次下降且互不重叠，是标准下跌趋势，但 ZS9/ZS10
    首笔都是向上笔，被旧判据全部滤掉（旧判据数到 0，新判据数到 3）。
    第17课「趋势就是至少两个以上同级别中枢的依次上升或依次下降」——方向由**相邻中枢
    的相对位置**给出（`nxt.hi < prev.lo` / `nxt.lo > prev.hi`），且只取**时间上连续**
    的一段（"依次"，不许跳过中间中枢凑数）。
  - **不许用未来结构**：`a+A+b+B+c` 里 c 是**离开 B 之后**的段，所以参与判定的中枢必须
    满足 `zs.edt <= c.sdt`（走完才算）。否则"低点本身就构成后一个中枢的 DD"那种位置
    （如分众 2026-08-21 的 4.7898）会把反转中枢当成趋势的第二个中枢，回过头来给该低点
    发一买 —— 那是拿结果标注原因。加约束前该样本会误报 `B1 @08-21 4.7898`，加约束后
    正确消失。
  - **位置条件**：c 段必须跌出趋势链**最后一个**中枢，即 `c.low < ZD`（一卖对称
    `c.high > ZG`）。依据第17课"下跌走势完成的关节点"与第27课"第一类买点肯定是趋势
    背驰构成的"。缺这道检查时，只要 MACD 面积/DIF 缩了，一个**根本没跌出中枢**的回调
    （价格还停在 `[ZD,ZG]` 内）也会被判成一买。
  - 回归测试：`test_trend_chain_counts_descending_zs_regardless_of_first_bi`（三个依次
    下降的中枢，后两个首笔向上 → 新判据数到 3、旧字段判据只数到 1）、
    `test_trend_chain_rejects_non_monotonic_sequence`、
    `test_b1_requires_c_bi_below_last_zs` / `test_b1_fires_when_c_bi_breaks_last_zs`。
- **趋势背驰的 split 面积兜底**：`check_trend_divergence` 原先没有 `split → total_abs`
  的短笔暖机兜底，而 `check_consolidation_divergence` 有 —— 同一份数据两种口径，是一种
  内部不一致。当某一段整段落在零轴同侧反向（典型的单根 K 线长影线砸出新低、柱状已翻红）
  时 `area=None`，趋势背驰就被直接判死。实测分众 30 分钟 `2026-06-29 @4.4142`（全窗口
  最低点，单根 30 分钟 K 线长下影）即属此列。现补上同样的兜底，仅替换 `None` 值。
- **B2/S2**：`sublevel_verifier(dt)` 的返回值必须作为**必要条件**（定律一）。修复：
  ```python
  if div["is_divergence"] and (verifier is None or verifier(fallback_down.edt) is True):
      bs_points.append(...)
  ```
  去掉 `suppress(Exception)` 的静默吞错，改为记录 warning 并 fail-closed（无次级别数据则不输出 B2/S2，而非无条件输出）。
- **B3/S3**：去掉背驰前提，只保留第20课位置条件（离开段破 ZG/ZD + 回试不回中枢）。背驰作为"强度评级"的可选附加信息，不作为成立条件。
- **背驰**：面积与 DIF 改为"或"关系可配置（默认 OR，对齐第27课），保留严格 AND 模式供偏好保守者选。

#### 3.3.1 趋势背驰 vs 盘整背驰：V 型底为什么出不了 B1（第24课口径）

第24课原文：

> 「用MACD判断背驰，首先要有两段同向的趋势。同向趋势之间一定有一个盘整或反向趋势连接，
> 把这三段分别称为A、B、C段。**显然，B的中枢级别比A、C里的中枢级别都要大**……
> **A段之前，一定是和B同级别或更大级别的一个中枢**……
> 而**C段的走势类型完成时对应的MACD柱子面积比A段对应的面积要小**，这时候就构成标准的背弛。」

关键点：标准（趋势）背驰的 A 段与 C 段之间隔的是**一个中枢**；盘整背驰的 A、C 之间隔的只是
**一个盘整（次级别中枢）**。二者力度比较的形式相同，但前提不同，第24课明确要求区分。

由此产生一个**结构性盲区**：`build_zs_strict` 的中枢会一直延伸到"离开—回抽不再回到带内"才终止，
于是一个 V 型底的低点，几乎总是落在**最后一个中枢的形成过程之内**（成为它的 `DD`），而不是位于
最后一个中枢下方的独立 c 段。既然 c 段不独立存在，**趋势背驰**就无从成立。

分众 30 分钟 2025-11-21~2026-11-21 的两个底就是这种情形，逐个对号（A/C 均为同向下笔）：

| 低点 | 所处结构 | A 段力度 | C 段力度 | 判定 |
|---|---|---|---|---|
| `2026-06-29 4.4142`（全局最低，单根 K 线长下影） | ZS7 `[4.5093,4.6520]` 的 `DD`，即中枢形成中的第三笔低点 | 面积 0.6706 / DIF −0.0496 | 面积 0.1431（兜底后）/ DIF −0.0500 | **盘整背驰**（A、C 只隔一笔），非趋势背驰 |
| `2026-09-30 4.6300` | ZS10 `[4.6400,4.7900]` 的 `DD`，比 `ZD` 只低 1 分钱 | 面积 0.0777 / DIF −0.0012 | 面积 0.2616（**放大 3.4 倍**）/ DIF −0.0181（**走深**） | 加速下跌，**连盘整背驰也不成立** |

结论：该窗口内**不存在**第17课意义上的本级别一买 —— 不是引擎漏了，而是两个"底"都不满足
"趋势背驰"的前提。按第17课/第27课，一买必须是趋势背驰点；既然没有一买，以"一买后第一次回调
不破前低"定义的二买（第17课定律一的实现前提）自然也出不来。**B2 缺失的直接原因是它在
`bs_points.py` 里被写成 `if b1_bi_idx is not None and b1_bi_idx + 2 < n:`，B1 空则 B2 必空。**

这套结构里真正的可买点由**三买**承担，引擎已正确输出：`2026-07-17 @4.9085`（ZS7 三买）、
`2026-10-29 @5.1200`（ZS10 三买）—— 正是两次"中枢被向上离开、回抽不破 ZG"。

**待定口径**：若希望把"趋势末端的盘整背驰低点"也作为买点输出（实战派常这么做，缠师第24课
也承认盘整背驰可用于盘整中的短差），需要新增一个独立的买点类型（例如 `B1c`/类一买），
而不是把它塞进 B1 —— 否则"一买=趋势背驰"的定理就被破坏了。这是口径选择，尚未落地。

#### 3.3.2 A 段选取与 MACD 切片口径（汇川 30 分钟 2026-10-15 @48.52 案例）

两个连锁 bug，都由"先信算法、再按禅师原文对图"的流程暴露：

1. **A 段选取**：旧实现 `_find_trend_start_bi` 用"往回找更浅的同向笔"启发式，在
   48.52 处取到 09-02（DIF −0.162，趋势内部的段），而正确的 A 是 07-23~07-28（DIF
   −0.418）；且 a 取晚了把 ZS10 圈到范围外，三中枢下跌趋势被数成 1 个，B1 整体漏报。
   修复：先 `recent_trend_chain`（不由 a 圈范围、取包含最后一个中枢的连续链）定链，
   再 `_bi_before(chain[0].sdt)` 反推 A 段（第24课：A 段之前一定是和 B 同级别或更大
   级别的一个中枢，A 的终点就在链头中枢起点处）。
2. **MACD 切片**：`slice_macd_for_bi` 原用 `range_sdt/range_edt`（分型
   `fx_a.raw_bars[0] ~ fx_b.raw_bars[-1]`）。K 线包含处理会把分型窗口链到**前一段走势**
   的 bar：48.52 的下跌笔 `sdt=10-12 10:00`，但起点顶分型的 `raw_bars[0]` 被合并到
   `10-09 14:30`（48.85 低点后反弹区），其 DIF=−0.548 是 10-09 下跌腿的残留 —— c 段
   DIF 峰值被污染成 −0.548 < A 段 −0.418，背驰误判为不成立。相邻笔的 range 窗口还会
   互相重叠，使盘整背驰 a/c 面积重复计数。修复：切片改用笔本体 `sdt ~ edt`。

修复后（实用重叠口径，split 面积 + DIF，AND）：
`B1 @2026-10-15 10:00 48.52`（面积 5.0109→0.9279 缩 81%、DIF −0.399→−0.376 抬高），
`B2 @2026-10-23 10:00 48.99`（bi84 vs bi88 面积缩、DIF −0.847→−0.055 抬高）——与手工
分解完全一致。跨样本回归：分众 30 分钟全区间新增 `S1 @2025-06-05 6.7158` +
`S2 @2025-06-18`（趋势链 [01-21~02-06, 02-10~03-11, 03-14~04-28] 三中枢依次上升、
全部在 c 笔起点前结束，无未来函数），`B1 @2025-12-17 6.70` 保留。

#### 3.3.3 系统性防线：黄金快照回归（tests/test_czsc_golden_snapshots.py）

上述 bug 的共性教训：**所有修复都在 domain 层、全股票共享同一条代码路径**——不存在
"只修一只股票"的特判；但真正的暴露手段是"拦截引擎真实入参 + 与手工分解逐项比对"，
而既有单测全是手工构造的理想笔（`range=sdt`），咬不住适配层（分型 raw_bars 窗口、
MACD 预热路径）这类问题。防线固化：

- **快照录制**：拦截 service 层传入 `identify_bs_points` 的真实入参
  （bi_list / zs_list / macd_out / bar_dts / DivergenceConfig），存
  `tests/fixtures/czsc_golden_hc30.json`（汇川 30 分钟 2025-11-20~2026-11-21）与
  `czsc_golden_fz30.json`（分众同窗口）。无网络依赖，domain 层重放。
- **逐点断言**：汇川必须含 `B1 @2026-10-15 48.52` + `B2 @2026-10-23 48.99`；
  分众必须**无任何一/二类点**（4.4142 / 4.63 均为中枢 DD 内的盘整背驰低点，第 24 课
  前提不成立），三买 07-17 @4.9085 / 10-29 @5.12 必须在场；输出点集与录制时逐点相等。
- **已知残留的系统性风险**（记录在案，未修复）：
  1. **双 MACD 实现**：`precomputed_macd_points`（主工程全历史预热）与
     `macd_points_from_bars`（窗口内冷启动）数值不同，前者只在预计算失败时兜底，
     两条路径的背驰判定可能有边界差异。若出现"同一请求时而多一个点"，先查这里。
  2. **B1c/类一买口径未定**（见 3.3.1 待定口径）：趋势末端的盘整背驰低点严格口径下
     不输出，属产品口径选择而非 bug。

### 4.1 边界声明（必须诚实）

**缠师原文（108 课）不包含任何可机器校验的结构化数值标注** —— 没有给出某只股票的 `[ZD,ZG]` 具体数值表、也没有买卖点的精确 OHLC 数据文件。原文案例（601628 人寿 2007、000002 万科 2006、600497 驰宏锌锗 2004-2005）用的是 2004-2007 年行情，本地数据仅覆盖 2020-2026，**时间不重叠，无法做数值复现**。

1. **公式一致性**：用原文数学公式（第18/20课中枢公式、第20课三买位置条件、第37课创新高低）在真实数据上断言实现输出满足公式。
2. **定理一致性**：断言实现满足原文定理（趋势中枢不重叠、二买=次级别一买、三买位置约束）。

### 7.2 关键设计决策：趋势重叠双模式

实施中发现一个必须诚实处理的问题：缠师第20课"中枢波动区间 `[DD,GG]` 绝对不重叠"是**严格级别中枢**的判据；工程是**笔级近似**，同向中枢常因共享价格带而波动区间重叠。若一律套用严格判据，实测 20 只股票 2 年窗口内 B1/S1 产出为 **0**——一类买卖点功能失效。

因此提供双模式（默认 strict）：
- `strict`：用 `[DD,GG]` 判重叠，完全对齐缠师第20课；笔级下趋势信号稀少（这是真实理论局限，非 bug）。
- `practical`：用核心区间 `[ZD,ZG]` 判重叠，笔级合理近似；同 20 只样本恢复 9 个 B1/S1。

两种模式均在 API 暴露并在缓存键中区分，用户可按需选择，绝不隐瞒差异。

### 3.2.3 回抽确认的最小进入深度（噪声过滤，2026-11-22 新增/调整）

定理二/三原本的回抽判定是「回抽笔与 `[ZD,ZG]` 有交集即算回到中枢」，这会让
**噪声级擦边**被当成有效回抽。实例：汇川技术日线 `2025-02-14`，回抽低点
`63.8495`，`ZG=63.866986`，只进入 **0.0175 元** —— K 线图上几乎贴着 ZG。

修复：`build_zs_strict(bis, min_pullback_depth=0, min_pullback_ratio=0.02,
pullback_base='zg')`，回抽笔与中枢的**重叠长度**必须 **严格大于**阈值才算
有效回抽，否则判定理三破坏：
```
base_value = ZG if base='zg' else (ZG - ZD)
threshold  = round(max(min_depth, min_ratio * base_value), 10)
overlap    = min(nxt.high, ZG) - max(nxt.low, ZD)
if overlap <= threshold: leave_idx = j   # 未回 -> 破坏
```

**基准选 ZG（默认）而非中枢高度的依据（禅师原文口径）**：
1. **对称性**：第20课三买「回试低点不跌入中枢区间」以 **ZG** 为锚；破坏是其
   对称面（回抽有效跌破 ZG），理应用同一把尺子，原文没有用中枢高度的用法。
2. **边界 vs 派生量**：中枢是「买卖双方阵地战之区域」，ZG 是阵地上沿。判定
   「是否重新进入阵地」参照边界，而非阵地宽度；宽度宽窄不一会让阈值语义漂移。
3. **跨标的语义一致**：2% 即价格回撤 2%，2 元股与 1000 元股含义相同。

配置项：`DivergenceConfig.zs_pullback_base`（zg/height）、`zs_pullback_min_ratio`
（默认 0.02）、`zs_pullback_min_depth`（默认 0 关闭）；贯通归一化、缓存键、
`from_query`（`bs_zs_pullback_base` / `bs_zs_pullback_min_ratio` /
`bs_zs_pullback_min_depth`）、API 同步/stream 两个路由。前端设置抽屉「缠论分析
设置 → 背驰判据设置」提供 **基准下拉（中枢上沿 ZG / 中枢高度）+ 1% / 2% 快捷按钮**，
默认 ZG 2%。

边界语义：**只有严格大于才算回踩，等于阈值也不算**（浮点 round 到 10 位消除尾差）。

回归测试：`test_zs_pullback_min_ratio_rejects_eyebrow_touch`、
`test_zs_pullback_min_ratio_boundary_is_strictly_less`、
`test_zs_pullback_base_zg_vs_height`。实测汇川日线 ZS0 正确终止于 `2025-01-06`。

注意：这是**噪声过滤口径**，不是对定理二的修改；比例设为 0 即回到严格原文。

#### 3.3.1 趋势背驰 vs 盘整背驰：V 型底为什么出不了 B1（第24课口径）

第24课原文：

> 「用MACD判断背驰，首先要有两段同向的趋势。同向趋势之间一定有一个盘整或反向趋势连接，
> 把这三段分别称为A、B、C段。**显然，B的中枢级别比A、C里的中枢级别都要大**……
> **A段之前，一定是和B同级别或更大级别的一个中枢**……
> 而**C段的走势类型完成时对应的MACD柱子面积比A段对应的面积要小**，这时候就构成标准的背弛。」

关键点：标准（趋势）背驰的 A 段与 C 段之间隔的是**一个中枢**；盘整背驰的 A、C 之间隔的只是
**一个盘整（次级别中枢）**。二者力度比较的形式相同，但前提不同，第24课明确要求区分。

由此产生一个**结构性盲区**：`build_zs_strict` 的中枢会一直延伸到"离开—回抽不再回到带内"才终止，
于是一个 V 型底的低点，几乎总是落在**最后一个中枢的形成过程之内**（成为它的 `DD`），而不是位于
最后一个中枢下方的独立 c 段。既然 c 段不独立存在，**趋势背驰**就无从成立。

分众 30 分钟 2025-11-21~2026-11-21 的两个底就是这种情形，逐个对号（A/C 均为同向下笔）：

| 低点 | 所处结构 | A 段力度 | C 段力度 | 判定 |
|---|---|---|---|---|
| `2026-06-29 4.4142`（全局最低，单根 K 线长下影） | ZS7 `[4.5093,4.6520]` 的 `DD`，即中枢形成中的第三笔低点 | 面积 0.6706 / DIF −0.0496 | 面积 0.1431（兜底后）/ DIF −0.0500 | **盘整背驰**（A、C 只隔一笔），非趋势背驰 |
| `2026-09-30 4.6300` | ZS10 `[4.6400,4.7900]` 的 `DD`，比 `ZD` 只低 1 分钱 | 面积 0.0777 / DIF −0.0012 | 面积 0.2616（**放大 3.4 倍**）/ DIF −0.0181（**走深**） | 加速下跌，**连盘整背驰也不成立** |

结论：该窗口内**不存在**第17课意义上的本级别一买 —— 不是引擎漏了，而是两个"底"都不满足
"趋势背驰"的前提。按第17课/第27课，一买必须是趋势背驰点；既然没有一买，以"一买后第一次回调
不破前低"定义的二买（第17课定律一的实现前提）自然也出不来。**B2 缺失的直接原因是它在
`bs_points.py` 里被写成 `if b1_bi_idx is not None and b1_bi_idx + 2 < n:`，B1 空则 B2 必空。**

这套结构里真正的可买点由**三买**承担，引擎已正确输出：`2026-07-17 @4.9085`（ZS7 三买）、
`2026-10-29 @5.1200`（ZS10 三买）—— 正是两次"中枢被向上离开、回抽不破 ZG"。

**待定口径**：若希望把"趋势末端的盘整背驰低点"也作为买点输出（实战派常这么做，缠师第24课
也承认盘整背驰可用于盘整中的短差），需要新增一个独立的买点类型（例如 `B1c`/类一买），
而不是把它塞进 B1 —— 否则"一买=趋势背驰"的定理就被破坏了。这是口径选择，尚未落地。

#### 3.3.2 A 段选取与 MACD 切片口径（汇川 30 分钟 2026-10-15 @48.52 案例）

两个连锁 bug，都由"先信算法、再按禅师原文对图"的流程暴露：

1. **A 段选取**：旧实现 `_find_trend_start_bi` 用"往回找更浅的同向笔"启发式，在
   48.52 处取到 09-02（DIF −0.162，趋势内部的段），而正确的 A 是 07-23~07-28（DIF
   −0.418）；且 a 取晚了把 ZS10 圈到范围外，三中枢下跌趋势被数成 1 个，B1 整体漏报。
   修复：先 `recent_trend_chain`（不由 a 圈范围、取包含最后一个中枢的连续链）定链，
   再 `_bi_before(chain[0].sdt)` 反推 A 段（第24课：A 段之前一定是和 B 同级别或更大
   级别的一个中枢，A 的终点就在链头中枢起点处）。
2. **MACD 切片**：`slice_macd_for_bi` 原用 `range_sdt/range_edt`（分型
   `fx_a.raw_bars[0] ~ fx_b.raw_bars[-1]`）。K 线包含处理会把分型窗口链到**前一段走势**
   的 bar：48.52 的下跌笔 `sdt=10-12 10:00`，但起点顶分型的 `raw_bars[0]` 被合并到
   `10-09 14:30`（48.85 低点后反弹区），其 DIF=−0.548 是 10-09 下跌腿的残留 —— c 段
   DIF 峰值被污染成 −0.548 < A 段 −0.418，背驰误判为不成立。相邻笔的 range 窗口还会
   互相重叠，使盘整背驰 a/c 面积重复计数。修复：切片改用笔本体 `sdt ~ edt`。

修复后（实用重叠口径，split 面积 + DIF，AND）：
`B1 @2026-10-15 10:00 48.52`（面积 5.0109→0.9279 缩 81%、DIF −0.399→−0.376 抬高），
`B2 @2026-10-23 10:00 48.99`（bi84 vs bi88 面积缩、DIF −0.847→−0.055 抬高）——与手工
分解完全一致。跨样本回归：分众 30 分钟全区间新增 `S1 @2025-06-05 6.7158` +
`S2 @2025-06-18`（趋势链 [01-21~02-06, 02-10~03-11, 03-14~04-28] 三中枢依次上升、
全部在 c 笔起点前结束，无未来函数），`B1 @2025-12-17 6.70` 保留。

#### 3.3.3 系统性防线：黄金快照回归（tests/test_czsc_golden_snapshots.py）

上述 bug 的共性教训：**所有修复都在 domain 层、全股票共享同一条代码路径**——不存在
"只修一只股票"的特判；但真正的暴露手段是"拦截引擎真实入参 + 与手工分解逐项比对"，
而既有单测全是手工构造的理想笔（`range=sdt`），咬不住适配层（分型 raw_bars 窗口、
MACD 预热路径）这类问题。防线固化：

- **快照录制**：拦截 service 层传入 `identify_bs_points` 的真实入参
  （bi_list / zs_list / macd_out / bar_dts / DivergenceConfig），存
  `tests/fixtures/czsc_golden_hc30.json`（汇川 30 分钟 2025-11-20~2026-11-21）与
  `czsc_golden_fz30.json`（分众同窗口）。无网络依赖，domain 层重放。
- **逐点断言**：汇川必须含 `B1 @2026-10-15 48.52` + `B2 @2026-10-23 48.99`；
  分众必须**无任何一/二类点**（4.4142 / 4.63 均为中枢 DD 内的盘整背驰低点，第 24 课
  前提不成立），三买 07-17 @4.9085 / 10-29 @5.12 必须在场；输出点集与录制时逐点相等。
- **已知残留的系统性风险**（记录在案，未修复）：
  1. **双 MACD 实现**：`precomputed_macd_points`（主工程全历史预热）与
     `macd_points_from_bars`（窗口内冷启动）数值不同，前者只在预计算失败时兜底，
     两条路径的背驰判定可能有边界差异。若出现"同一请求时而多一个点"，先查这里。
  2. **B1c/类一买口径未定**（见 3.3.1 待定口径）：趋势末端的盘整背驰低点严格口径下
     不输出，属产品口径选择而非 bug。

## 4. 验证方案与诚实边界

### 4.1 边界声明（必须诚实）

**缠师原文（108 课）不包含任何可机器校验的结构化数值标注** —— 没有给出某只股票的 `[ZD,ZG]` 具体数值表、也没有买卖点的精确 OHLC 数据文件。原文案例（601628 人寿 2007、000002 万科 2006、600497 驰宏锌锗 2004-2005）用的是 2004-2007 年行情，本地数据仅覆盖 2020-2026，**时间不重叠，无法做数值复现**。

因此本设计不做"与缠师数值一致"的虚假校验，而做两类可验证的一致性：

1. **公式一致性**：用原文数学公式（第18/20课中枢公式、第20课三买位置条件、第37课创新高低）在真实数据上断言实现输出满足公式。
2. **定理一致性**：断言实现满足原文定理（趋势中枢不重叠、二买=次级别一买、三买位置约束）。

### 7.2 关键设计决策：趋势重叠双模式

实施中发现一个必须诚实处理的问题：缠师第20课"中枢波动区间 `[DD,GG]` 绝对不重叠"是**严格级别中枢**的判据；工程是**笔级近似**，同向中枢常因共享价格带而波动区间重叠。若一律套用严格判据，实测 20 只股票 2 年窗口内 B1/S1 产出为 **0**——一类买卖点功能失效。

因此提供双模式（默认 strict）：
- `strict`：用 `[DD,GG]` 判重叠，完全对齐缠师第20课；笔级下趋势信号稀少（这是真实理论局限，非 bug）。
- `practical`：用核心区间 `[ZD,ZG]` 判重叠，笔级合理近似；同 20 只样本恢复 9 个 B1/S1。

两种模式均在 API 暴露并在缓存键中区分，用户可按需选择，绝不隐瞒差异。

### 3.2.3 回抽确认的最小进入深度（噪声过滤，2026-11-22 新增）

定理二/三原本的回抽判定是"回抽笔与 `[ZD,ZG]` 有交集即算回到中枢"，这会让
**噪声级擦边**被当成有效回抽。实例：汇川技术日线 `2025-02-14`，回抽低点
`63.8495`，`ZG=63.866986`，只进入 **0.0175 元** —— K 线图上几乎贴着 ZG，
但按旧规则中枢继续延伸到 `2025-06-23`。

修复：`build_zs_strict(bis, min_pullback_depth=0.1, min_pullback_ratio=0.0)`，
回抽笔与中枢的**重叠长度**必须 `>= threshold` 才算有效回抽，否则判定理三破坏：
```
threshold = max(min_pullback_depth, min_pullback_ratio * (ZG - ZD))
overlap   = min(nxt.high, ZG) - max(nxt.low, ZD)
if overlap < threshold: leave_idx = j   # 未回 -> 破坏
```
- 默认 `0.1` 元：擦边 0.0175 判为未回，汇川日线 ZS0 正确终止于 `2025-01-06`。
- 可选 `ratio`：按中枢高度比例，适配 2 元股/1000 元股不能用同一绝对阈值的问题
  （默认 0 关闭）。两者取大。
- 参数经 `DivergenceConfig` 贯通归一化、缓存键、`AnalyzeRequest.from_query`
  （`bs_zs_pullback_min_depth` / `bs_zs_pullback_min_ratio`）。
- 边界语义：**只有大于阈值才算回踩，等于或小于都不算**（`overlap < threshold` 破坏）。
- 回归测试：`test_zs_pullback_min_depth_rejects_eyebrow_touch`、
  `test_zs_pullback_min_depth_boundary_is_strictly_less`、
  `test_zs_pullback_min_ratio_scales_with_center_height`。
- 注意：这是**噪声过滤口径**，不是对定理二的修改；阈值设为 0 即回到严格原文。
