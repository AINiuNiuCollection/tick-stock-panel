# 第四阶·致用篇：孙子兵法在股市投资中的实战应用

> **教学定位：** 全套教材的核心章节。前三阶解决了"是什么、怎么想、为什么"的问题，本阶解决"怎么做"的问题。
>
> **学习前提：** 已学完前三阶（启蒙篇、筑基篇、明理篇），理解五事七计、先胜后战、避实击虚等核心概念。
>
> **学习目标：** 能用兵法框架完成一次完整的交易决策，从选股、风控、建仓、持仓到退出，每一步都有兵法依据。
>
> **学习时长：** 1-2周（建议精读+对照自己过往交易复盘）

## 前言：从"懂"到"用"是最大的跨越

### 0.1 为什么这一阶最难

读到这里，你应该已经能背几句原文、能讲几个概念、能说出一两条"兵法对应交易"的道理。但这远远不够。

**真懂和会用之间，隔着一整个太平洋。**

打个比方：你看过一千本游泳教材，下水那一刻还是会呛水。因为水里多了一个东西——**你自己**。水温、水流、你的体力、你的恐惧、你的呼吸节奏……这些教材里没有，但决定了你是浮起来还是沉下去。

股市也一样。前三阶讲的是"兵法应该怎么用"，你点头称是。但真到了交易界面：

- 明明计划9.5元止损，跌到9.5时你脑子里响起的是"再等等，可能反弹"；
- 明明不该追高，看到一根大阳线你手比脑子快；
- 明明应该空仓等待，你受不了空仓的"踏空焦虑"，硬找一个理由开仓；
- 明明只该买20%仓位，鬼使神差地点了"全仓买入"。

**你背过的所有兵法，在情绪面前不堪一击。**

所以这一阶的重点不是再讲一遍理论，而是：**怎么把兵法从"知道"变成"做到"。**

### 0.2 兵法不是教你怎么赚钱，是教你怎么不亏钱

这是本阶最重要的一句话，请读三遍。

> **兵法不教你怎么赚钱，兵法教你的是怎么不亏钱。不亏了，赚钱是早晚的事。**

《孙子兵法》全书的核心精神是**先胜后战**——胜利在开打之前就已经决定了。翻译成交易语言：**一笔交易在按下买入键之前，结局基本已经写好了。**

- 你在哪儿研究、研究了什么、定了什么纪律、用什么仓位、设了什么止损——这些决定了90%的结局
- 按下买入键之后发生的事，只决定剩下的10%

大多数散户把这个比例搞反了：90%的精力花在看盘、看消息、看K线，10%的精力（甚至没有）花在事前研究和纪律制定。难怪亏钱。

兵法思维的核心是**反过来**：

- 90%的精力用于事前：研究、计划、定纪律、评估确定性
- 10%的精力用于事中：执行计划、监控偏离
- 事后：复盘，不懊悔

### 0.3 本阶怎么读

本阶共九章，每章都遵循一个结构：

```
原文引用 → 股市解读 → 详细实例 → 实操指南
```

**建议读法：**

1. **第一遍通读**：建立整体印象，知道兵法能落地到哪些交易环节
2. **第二遍精读**：每读一章，对照自己最近一笔交易，问"我做到了吗？违背了哪条？"
3. **第三遍实操**：用本阶给的框架，做一次完整的交易计划（哪怕不真买，模拟也行）

读完本阶的通过标准：**能用本阶的"完整交易流程兵法化"框架，对一笔真实或模拟交易做出完整决策，并说出每一步的兵法依据。**

## 术语速查表

本篇会用到不少股市术语。如果你是第一次接触，别慌——下面这张表把所有术语都用"一句话解释+生活化比喻"列出来了。

| 术语 | 一句话解释 | 生活化比喻 |
|------|-----------|-----------|
| PE（市盈率） | 股价÷每股利润 | 花多少年能靠利润回本 |
| PB（市净率） | 股价÷每股净资产 | 买这公司花了几倍"家底"的钱 |
| ROE（净资产收益率） | 净利润÷净资产 | 公司用自家家底赚钱的效率 |
| 均线（MA5/MA20/MA60） | 过去5/20/60天平均股价连成的线 | 一段时间内大家的"平均成本线" |
| K线 | 一天内开盘、收盘、最高、最低价画的柱状图 | 一天的"战报图"——一栏看胜负 |
| 龙虎榜 | 当日异动股的买卖前五席位公开榜 | 主力"露脸名单"——谁在买谁在卖 |
| 北向资金 | 从香港流入A股的资金 | 被看作"聪明钱"，外资的风向标 |
| 融资融券 | 借钱买股/借股卖出 | 加杠杆的"贷款工具"——风险翻倍 |
| 换手率 | 一天内成交量÷流通股本 | 这只票今天"转手了几遍" |
| 振幅 | 当天最高-最低价÷昨日收盘价 | 今天价格"上下晃了多大幅度" |
| 量比 | 当日成交量÷过去5日平均成交量 | 今天的动静比平时"放大了几倍" |
| MACD | 一种判断趋势强弱的指标 | 看"风是在变大还是变小"的工具 |
| 布林带 | 由中轨+上下轨组成的价格通道 | 价格的"晃动范围带"——出轨道要警惕 |
| 止损 | 跌到预设价位无条件卖出 | "认输线"——亏到这里就停，不再加码 |
| 仓位 | 投入资金占总资金的比例 | 战场上"派出去多少兵力" |
| 涨停/跌停 | 当日涨/跌到最大限制（A股一般10%） | 价格被"封顶/封底"，想买卖也成交不了 |
| 散户 | 个人投资者 | 兵法里的"散兵游勇"——单兵作战 |
| 主力 | 大资金机构 | 兵法里的"正规军"——能影响战局 |
| 大盘 | 整个市场的总体走势（如上证指数） | 战场的"整体天气"——晴雨都要看 |
| 蓝筹股 | 业绩稳定、市值大、分红好的龙头股 | 兵法里的"老将"——稳但慢 |

后面的内容中遇到这些词，可以随时回来查。

## 一、选股研究体系——"知己知彼"

> **原文：** "知彼知己者，百战不殆；不知彼而知己，一胜一负；不知彼不知己，每战必殆。"——《谋攻篇》
>
> **原文：** "知己知彼，胜乃不殆；知天知地，胜乃可全。"——《地形篇》

### 1.1 知彼：研究标的

"彼"就是你的交易对手，也是你要买入的标的。在股市里，**"彼"有三层：基本面（地）、技术面（天）、资金面（将）。**

#### 1.1.1 基本面研究——对应"地"

> **原文：** "夫地形者，兵之助也。料敌制胜，计险厄远近，上将之道也。"——《地形篇》

"地"是战场的物理环境。在股市里，**基本面就是"地"——它是标的的客观现实。**

研究一家公司，至少要回答以下问题：

| 维度 | 关键问题 | 查看资料 |
|------|----------|----------|
| 盈利能力 | 公司赚钱吗？赚的是什么钱？能持续吗？ | 利润表、毛利率、净利率、ROE |
| 护城河 | 公司的竞争优势是什么？能挡住对手多久？ | 行业地位、品牌、专利、网络效应、规模 |
| 行业地位 | 公司在行业里排第几？行业本身在成长还是衰退？ | 行业报告、市占率、行业增速 |
| 财务健康 | 资产负债表干净吗？现金流真实吗？ | 资产负债率、经营现金流、应收账款 |
| 估值水平 | 现在的价格贵不贵？相对历史、相对同行呢？ | PE、PB、PS、PEG、股息率 |
| 公司治理 | 管理层靠谱吗？有没有掏空上市公司的迹象？ | 关联交易、质押率、高管减持记录 |

**为什么"地"最重要？** 因为地形是客观的，不随情绪波动。一只股票短期可以因为情绪涨跌，长期必然回归基本面——这是"地"的引力。

#### 1.1.2 技术面研究——对应"天"

> **原文：** "天者，阴阳、寒暑、时制也。"——《始计篇》

"天"是天时，是气候变化。在股市里，**技术面就是"天"——它反映市场情绪的冷热周期。**

技术面研究至少看三层：

1. **趋势层**：当前是上升、下降还是震荡？均线系统多头排列还是空头排列？
2. **结构层**：价格在什么位置？关键支撑压力位在哪？有没有突破、回踩、背离？
3. **量能层**：上涨有没有量能配合？缩量上涨和放量上涨含义完全不同。

技术面不预测未来，它**告诉你"现在市场处于什么状态"**。这个状态是基本面和市场情绪共同作用的结果。

#### 1.1.3 资金面研究——对应"将"

> **原文：** "将者，智、信、仁、勇、严也。"——《始计篇》

"将"是统帅。在股市里，**资金面就是"将"——主力资金是战场上的统帅，它决定方向。**

资金面研究包括：

- **主力动向**：龙虎榜上有没有机构席位？大宗交易是折价还是溢价？
- **机构持仓**：基金季报里有没有加仓减仓？北向资金流入还是流出？
- **融资融券**：融资余额是增加还是减少？融券余量有没有异常？
- **股东人数**：股东人数减少（筹码集中）通常意味着主力在吸筹；股东人数暴增则要警惕派发。

**"将"的判断标准：跟着聪明的钱走，不跟着噪音走。**

#### 1.1.4 实例：买入前应该研究什么

**场景：** 假设你注意到"中远海控"（虚构的典型场景，非真实推荐）近期走势较强，想买入。按"知彼"框架，买入前应该研究：

**第一层·地（基本面）：**
- 公司主业是集装箱运输，盈利与全球贸易景气高度相关
- 看 最近三年财报：营收、净利润、ROE、现金流是否健康
- 看行业：集运行业周期性强，当前处于景气周期的哪个阶段？
- 看估值：当前PE相对历史分位是高还是低？相对同行呢？
- 看分红：高股息率是否能持续？分红率多少？

**第二层·天（技术面）：**
- 看周线和月线：长期趋势是上升还是下降？
- 看日线：近期有没有突破关键阻力位？均线排列如何？
- 看量能：上涨时放量还是缩量？回调时缩量还是放量？
- 看位置：当前价格离近一年高点、低点各有多远？

**第三层·将（资金面）：**
- 看龙虎榜：最近有没有机构席位买入？
- 看北向资金：近一个月是流入还是流出？
- 看融资余额：是上升还是下降？
- 看股东人数：最近一期是否在减少？

**研究结论模板：**

```
标的：中远海控（虚构示例）
研究日期：2026-XX-XX

【地·基本面】
- 主业：集装箱运输，强周期
- 财务：近三年ROE均值XX%，经营现金流为正且稳定
- 估值：PE XX倍，处于近五年XX%分位
- 护城河：全球前X大集运公司，规模优势+航线网络
- 风险：周期顶部风险，全球贸易下行风险

【天·技术面】
- 长期：月线处于XX趋势
- 中期：周线XX
- 短期：日线XX，关键支撑XX元，关键压力XX元
- 量能：上涨放量/缩量，回调放量/缩量

【将·资金面】
- 龙虎榜：近期有/无机构席位
- 北向资金：近一月净流入/流出XX亿
- 融资余额：近一月增加/减少XX亿
- 股东人数：环比减少/增加XX%

【综合判断】
- 确定性等级：高/中/低
- 主要逻辑：XXX
- 主要风险：XXX
- 是否纳入观察池：是/否
```

**填写范例（虚构示例，非投资建议）：**

```
标的：中远海控（虚构示例）
研究日期：2024-03-15

【地·基本面】
- 主业：集装箱运输，强周期
- 财务：近三年ROE均值22%，经营现金流为正且稳定
- 估值：PE 8.5倍，处于近5年15%分位（历史低位）
- 护城河：全球前3大集运公司，规模优势+航线网络
- 风险：周期顶部风险，全球贸易下行风险
- 股息率：7.3%，分红率约50%

【天·技术面】
- 长期：月线处于底部震荡，长期下降趋势尚未反转
- 中期：周线站上60周均线，初步走平
- 短期：日线站上60日均线，MACD金叉，关键支撑9.5元，关键压力11元
- 量能：近期上涨放量，回调缩量，量价配合良好

【将·资金面】
- 龙虎榜：近一月有2次机构席位买入
- 北向资金：近一月净流入12亿
- 融资余额：近一月增加8亿
- 股东人数：环比减少4%（筹码集中）

【综合判断】
- 确定性等级：较高（趋势初步形成+基本面支撑强+资金流入）
- 主要逻辑：低估值+高分红+资金流入+周期底部反转预期
- 主要风险：全球贸易下行超预期、运价继续走低
- 五事评分：7/10
- 是否纳入观察池：是
- 后续动作：等回踩10元附近分批建仓，首批仓位不超过15%
```

**注意：** 这个研究做完，**不要立刻买**。这只是"知彼"，还要"知己"，还要"庙算"。研究只解决"标的不标"的问题，不解决"该不该买、买多少"的问题。

### 1.2 知己：了解自己

> **原文：** "知己知彼，胜乃不殆。"——《地形篇》

大多数投资者研究标的很认真，研究自己很敷衍。**亏钱的人，70%是输给自己，不是输给市场。**

"知己"要回答四个问题：

#### 1.2.1 风险承受能力——你能承受多大回撤？

这是最基础的问题，也是最容易被高估的问题。

**自测方法：**
- 回顾你最大的一笔亏损，当时的金额占你总资金的比例是多少？
- 那笔亏损让你失眠了吗？影响了工作和生活吗？
- 如果再来一次同样的亏损，你能平静接受吗？

**经验法则：**
- 让你失眠的回撤，就是你的真实承受能力上限
- 不要相信"我能承受50%回撤"——除非你真经历过且没崩溃
- 大多数人的真实承受能力是10-20%总资金回撤

**对应仓位：**
- 总资金回撤承受能力 = 单笔止损上限 × 同时持仓数量
- 例：总资金100万，承受能力15%，单笔止损2% → 同时持仓最多7-8只，每只仓位约12-15%

#### 1.2.2 投资周期——短线还是长线？

这不是"你想做短线还是长线"，而是"你的资金性质和性格适合短线还是长线"。

| 类型 | 资金性质 | 性格要求 | 时间投入 |
|------|----------|----------|----------|
| 短线（持仓数日-数周） | 闲钱，短期不用 | 反应快、纪律严、能盯盘 | 每天1-2小时 |
| 中线（持仓数月） | 闲钱，半年不用 | 耐心、能忍受中间波动 | 每周2-3小时 |
| 长线（持仓1年以上） | 闲钱，3-5年不用 | 信仰型、能忍受大幅回撤 | 每月几小时 |

**常见错误：**
- 想做长线却天天看盘，被短期波动震出局
- 想做短线却不设止损，短线变长线，长线变深套
- 资金性质和投资周期错配（用下个月要还房贷的钱做长线）

#### 1.2.3 能力圈——这只股票你看得懂吗？

> **原文：** "不知军之不可以进，而谓之进；不知军之不可以退，而谓之退——是谓縻军。"——《谋攻篇》

不懂的不做，是兵法的硬要求。

**能力圈自测三问：**
1. **能用三句话向一个外行说清楚这家公司是怎么赚钱的吗？** 说不出 = 不在能力圈内
2. **能说出这家公司未来三年最大的三个风险吗？** 说不全 = 不在能力圈内
3. **如果这只股票跌30%，你知道是因为什么吗？** 不知道 = 不在能力圈内

**能力圈的边界比大小重要。** 巴菲特几十年不碰科技股不是因为他不懂，是因为他知道科技股不在他的能力圈中心。后来他买苹果，是因为他确认苹果已经从"科技公司"变成了"消费品公司"——进入了他的能力圈。

#### 1.2.4 情绪弱点——你容易追涨还是容易割肉？

每个人都有自己的情绪死穴。常见类型：

| 类型 | 表现 | 典型场景 | 对策 |
|------|------|----------|------|
| 追涨型 | 看到涨就怕踏空，忍不住追 | 大阳线、连板 | 强制24小时冷静期 |
| 割肉型 | 一跌就慌，止损位形同虚设 | 阴跌、突然跳水 | 用条件单机械止损 |
| 死扛型 | 亏了不止损，"总会回来" | 深套 | 单笔止损硬规则 |
| 加仓型 | 亏损后越跌越买，摊低成本 | 下降趋势中 | 严禁在亏损方向加仓 |
| 跳车型 | 频繁换股，追热点 | 板块轮动 | 限制每月交易次数 |
| 懊悔型 | 卖飞后反复懊悔，影响后续 | 卖出后大涨 | 接受卖飞是常态 |

**自测：** 回顾过去一年你最懊悔的5笔交易，归类一下，你的情绪死穴是哪一类？这一类就是你要重点防范的。

#### 1.2.5 实例：同一只股票，不同性格的人应该有完全不同的操作

**场景：** 假设某只新能源股票"XYZ"（虚构），当前价20元，基本面尚可，技术面刚突破长期下降趋势。

| 投资者类型 | 应对方案 | 理由 |
|------------|----------|------|
| 张三（保守型，能承受10%回撤，长线资金） | 观望为主。等回调到18元附近分批建仓，仓位不超过15%，止损17元。 | 不追突破，等回踩确认。回撤承受能力低，仓位必须小。 |
| 李四（激进型，能承受30%回撤，短线资金） | 突破当日小仓试水（10%仓位），止损19元。若次日继续放量上攻，加仓到25%。 | 激进型可以追突破，但必须设硬止损。 |
| 王五（追涨型情绪弱点） | **不参与**。即使行情真的走了，也不参与。 | 追涨型在这种场景下极易重仓追高，然后被回踩震出局。宁可错过，不可做错。 |
| 赵六（能力圈不在新能源） | **不参与**。看不懂的不做。 | 不在能力圈内的标的，再好的机会也不是你的机会。 |

**关键认知：** 同一个标的、同一个时点，对不同人而言"该不该买、买多少、怎么买"的答案可以完全不同。**因为"己"不同，"彼"再好也不一定要做。**

### 1.3 信息不对称的消除

> **原文：** "先知者，不可取于鬼神，不可象于事，不可验于度，必取于人，知敌之情者也。"——《用间篇》

孙子说：想要事先了解情况，不能靠求神拜佛，不能靠类推猜测，不能靠主观臆断，必须从了解实际情况的人那里获取。

翻译成交易语言：**做决策要用可验证的信息，不能用猜测、不能用感觉、不能用不可验证的消息。**

#### 1.3.1 信息的三层分级

| 层级 | 来源 | 可信度 | 使用方式 |
|------|------|--------|----------|
| 一手信息 | 公司公告、财报、投资者调研、电话会议 | 最高 | 决策依据 |
| 二手信息 | 券商研报、专业财经媒体、知名大V观点 | 中等 | 参考、启发、交叉验证 |
| 三手信息 | 小道消息、论坛传言、群聊"内幕" | 极低 | **不用** |

**为什么三手信息不用？**
- 真的内幕你拿不到，能传到你耳朵里的"内幕"已经过了N手，要么是假的，要么是别人想让你接盘
- 即使是真的，"利用内幕交易"是违法的，盈亏同源，赚了也要赔回去
- 哪怕不违法，依赖三手信息会让你形成惰性，丧失独立研究能力

#### 1.3.2 二手信息的正确用法

券商研报和大V观点不是不能用，而是**不能直接用**。正确用法：

1. **当作线索，不当结论**——研报说"某股有催化剂"，你去验证催化剂是什么、是真的吗
2. **看逻辑，不看结论**——研报说"目标价XX元"不用管，但研报讲的产业逻辑要思考对不对
3. **交叉验证**——三家以上独立来源的同一观点，可信度提高
4. **反向思考**——研报一致看多时，反过来想"现在买入的对手是谁？为什么有人愿意卖给我？"

#### 1.3.3 实例：听到"某股要重组"的消息，正确的验证路径

**场景：** 你在一个炒股群里看到群友说"某医药股下周要停牌重组，注入优质资产，至少3个涨停"。

**错误做法：**
- 直接买入 → 大概率是被收割
- 半信半疑买入一点 → 心态不稳，涨一点就跑、跌一点就慌
- 朋友圈转发 → 助长谣言，可能害朋友

**正确验证路径（按时间顺序）：**

```
第1步：查公司公告
  └→ 巨潮资讯网/交易所网站，查最近三个月所有公告
  └→ 是否有"重大事项停牌""筹划重大资产重组"等公告？
  └→ 如果没有 → 消息大概率是假的，到此为止

第2步：查股东行为
  └→ 最近三个月有没有大股东减持、质押异常？
  └→ 如果大股东在减持 → 重组概率极低（大股东不会在重组前减持）
  └→ 如果大股东在增持、解押 → 有一定可能性

第3步：查股价异动
  └→ 最近一个月股价有没有异常放量、异动？
  └→ 如果已经大涨过 → 消息大概率已被消化，进去是接盘
  └→ 如果一直横盘 → 消息可能尚未反映，但真假仍未知

第4步：查基本面背景
  └→ 公司是否具备重组动机？（业绩差、大股东有未注入资产等）
  └→ 行业是否有整合趋势？
  └→ 如果毫无逻辑支撑 → 消息大概率是假的

第5步：决策
  └→ 即使前4步都"看起来像真的"，也绝不基于"未公告的重组消息"买入
  └→ 等正式公告出来再决定，错过前几个涨停没关系，避开大坑更重要
  └→ 重组失败复牌的暴跌，远比错过3个涨停的伤害大
```

**兵法依据：** "必取于人，知敌之情者也"——必须用可验证的信息，不可用不可验证的传言。**一笔交易的决策依据必须是"公开+可验证"的信息，否则你的"先知"就是赌博。**

## 二、风险管理体系——"先为不可胜"

> **原文：** "昔之善战者，先为不可胜，以待敌之可胜。不可胜在己，可胜在敌。故善战者，能为不可胜，不能使敌之可胜。故曰：胜可知，而不可为。"——《军形篇》

这是整部《孙子兵法》对交易最重要的两句话。请背下来。

**翻译成交易语言：**

> 善于交易的人，**先让自己处于不会爆仓的状态**，然后等待市场给出可以盈利的机会。
>
> 不会爆仓这件事，**由你自己控制**（仓位、止损、分散）；能不能抓住盈利机会，**由市场决定**（有没有趋势、有没有催化剂）。
>
> 所以善交易者，能保证自己不爆仓，但不能保证一定能赚到钱。
>
> **盈利是可以预见的，但不能强求。**

### 2.1 不可胜在己：你能控制的

"不可胜在己"——你能控制的是自己不爆仓。具体四个动作：

#### 2.1.1 仓位控制：永远不满仓加杠杆

**为什么不能满仓？**
- 满仓意味着你失去了应对意外的能力——任何突发利空你只能眼睁睁看着
- 满仓意味着你失去了加仓的能力——好机会出现时你只能干瞪眼
- 满仓意味着心理压力极大——任何波动都被放大到极致

**为什么不能加杠杆？**
- 杠杆放大盈利，也放大亏损
- 杠杆有强平线，等于给市场一个"杀死你"的按钮
- 杠杆让你失去时间——你等得起，融资融券等不起

**仓位控制的基本规则：**
- 单只股票不超过总仓位20%（即使确定性极高）
- 满仓上限80%，永远留20%现金应对意外
- 严禁使用融资融券、场外配资等任何杠杆工具

#### 2.1.2 止损设定：每笔交易预设止损位

**为什么必须止损？**
- 不止损 = 让市场决定你的最大亏损，这违反"不可胜在己"原则
- 一次不止损的深套，可以抹掉你一年的盈利
- 止损是"为不可胜"的最直接动作——把最大亏损锁死

**止损位怎么定？**
- **技术止损**：跌破关键支撑位、跌破均线、跌破前低
- **金额止损**：单笔亏损达到总资金2%无条件止损
- **逻辑止损**：买入逻辑被证伪（如买入是因为业绩拐点，业绩拐点被证伪）

**三种止损取最严格的那个。** 例：技术止损8%、金额止损2%（对应价格-5%）、逻辑止损未触发 → 实际止损位是-5%。

#### 2.1.3 分散配置：不把鸡蛋放一个篮子里

**分散的原则：**
- **行业分散**：不同行业之间不相关或负相关（如消费+科技+金融）
- **风格分散**：价值股+成长股+周期股搭配
- **时间分散**：分批建仓，不在同一时点 all-in

**分散不是越多越好：**
- 持仓3-5只是最优区间，超过10只就过度分散
- 过度分散 = 指数化 = 不如直接买指数基金
- 分散的目的是降低非系统性风险，不是消除所有风险

#### 2.1.4 现金储备：始终保持应对意外的弹药

**现金的作用：**
- 应对持仓股票的突发利空（停牌、暴雷）——你有现金补仓或调仓
- 抓住市场恐慌时出现的机会——大跌时现金最值钱
- 维持心理稳定——有现金就有底气，不会被深套逼疯

**现金比例：**
- 牛市可以低至20%
- 震荡市保持30-50%
- 熊市保持50%以上
- 极端恐慌时可以提高到80%以上，等待大级别机会

#### 2.1.5 100万资金风控完整算例

把上述四条规则（仓位、止损、分散、现金）落到一笔具体资金上，形成可执行的风控算例。

**100万资金风控算例（虚构示例，非投资建议）：**

风控看着复杂，其实就三步。每步只算一个数，算完你就知道"最多买几只、每只买多少、亏到哪卖"。

---

**第1步：算总仓位上限**

> 总资金 × 最高仓位比例 = 最多能投出去的钱

```
总资金：100万
最高仓位比例：80%（永远留20%现金）
→ 总仓位上限 = 100万 × 80% = 80万
```

**到此为止你只需要记住：你最多能动用的钱是80万，剩下20万碰都不许碰。**

---

**第2步：算单只止损额**

> 总资金 × 单只最大亏损比例 = 一只股票最多允许亏多少

```
总资金：100万
单只最大亏损比例：2%（硬规则，不可放宽）
→ 单只止损额 = 100万 × 2% = 2万
```

**到此为止你只需要记住：任何一只股票亏到2万，立刻无条件卖出，没有"再等等"。**

---

**第3步：算最多买几只**

> 总仓位上限 ÷ 单只仓位 = 最多能同时持几只

```
单只仓位上限：15万（按"单只不超过总仓位20%"的硬规则，这里取15%更保守）
最多持仓数 = 总仓位上限 ÷ 单只仓位 = 80万 ÷ 15万 ≈ 5只
```

**到此为止你只需要记住：最多同时持5只，每只最多投15万，每只最多亏2万——5只全亏最多亏10万，占总资金10%，不会让人失眠。**

---

三步算完，你的风控框架就立起来了：

```
====================================
总资金：100万
====================================

【现金储备】
- 现金留存：20万（20%），可用投资80万
- 现金作用：应对持仓突发利空、抓住恐慌机会、维持心理稳定

【仓位控制】
- 单只仓位上限：15万（15%，符合"单只不超过20%"硬规则）
- 同时持仓上限：5只
- 满仓上限：80万（80%），永远留20%现金

【止损规则】
- 单笔止损金额：2万（总资金2%）
- 单笔止损比例：2万/15万 = 13.3%
- 止损位计算公式：买入价 × (1 - 2万/15万) = 买入价 × 0.867

【极端情况回撤上限】
- 假设5只持仓同时触发止损：5 × 2万 = 10万
- 总资金最大回撤上限：10%（10万/100万）
- 这个回撤在大多数人承受能力范围内（10-20%）

【具体示例】
- 标的：某股，买入价10元/股
- 仓位：15万元 = 1.5万股
- 止损位：10 × 0.867 = 8.67元
- 跌破8.67元无条件卖出（建议用条件单机械执行）
- 最大亏损：15万 × 13.3% = 2万（恰好等于单笔止损上限）

【五只持仓的组合示例】
| 标的 | 行业 | 仓位 | 买入价 | 止损位 | 最大亏损 |
|------|------|------|--------|--------|----------|
| 股票A | 消费 | 15万 | 50元 | 43.35元 | 2万 |
| 股票B | 科技 | 15万 | 20元 | 17.34元 | 2万 |
| 股票C | 金融 | 15万 | 10元 | 8.67元 | 2万 |
| 股票D | 医药 | 15万 | 30元 | 26.01元 | 2万 |
| 股票E | 周期 | 15万 | 8元 | 6.94元 | 2万 |
| 现金 | - | 20万 | - | - | - |
| 合计 | - | 95万 | - | - | 10万 |

注：行业分散（消费/科技/金融/医药/周期，相关性低），
    单笔止损合计10万=总资金10%，在承受范围内。
====================================
```

**为什么这个算例有效？**
- 每条规则都可量化、可执行、可验证
- 任何一只股票的亏损被锁定在2万以内，不会"一笔爆仓全盘崩溃"
- 极端情况下总回撤10%，不会让人失眠，符合"先为不可胜"
- 保留20万现金，可在市场恐慌时抓住机会加仓，符合"以待敌之可胜"

**自测：** 按你的真实总资金，套用这个算例模板算一遍。问自己：单笔止损2%你能严格执行吗？如果答案是"看情况"，那你的风控规则还没真正立起来。

### 2.2 可胜在敌：等市场给机会

> **原文：** "善战者，立于不败之地，而不失敌之败也。是故胜兵先胜而后求战，败兵先战而后求胜。"——《军形篇》

**翻译：** 善于交易的人，先让自己处于不会爆仓的状态，然后等市场给出可以盈利的机会。盈利的交易者**先有把握再下单**，亏损的交易者**先下单再求盈利**。

#### 2.2.1 不强行交易：没有好机会就空仓等

**为什么大多数人做不到空仓？**
- "踏空焦虑"——看到别人赚钱比自己亏钱还难受
- "交易成瘾"——不开仓就手痒
- "过度自信"——总觉得"这次我能抓到机会"

**空仓是交易的一种状态，不是"不交易"。** 空仓 = 持有现金 = 持有期权 = 等待更好的机会。

**空仓的标准：**
- 没有符合自己策略的标的（不在能力圈、不符合买入条件）
- 市场整体处于下降趋势（系统性风险大）
- 持仓已满，新机会出现但无资金加仓（不要卖老仓位追新机会）

#### 2.2.2 耐心等待：好的交易机会是等出来的

**机会的两种来源：**
1. **市场恐慌时**：大跌之后的好公司，估值被砸到历史低位
2. **趋势确认时**：长期底部突破，新的上升趋势形成

**两种机会都需要等。** 第一种要等市场恐慌，第二种要等趋势确认。**强行找机会 = 找陷阱。**

#### 2.2.3 实例：2022-2024年A股熊市，空仓等待 vs 越跌越买的巨大差异

**背景：** 2022年初至2024年9月，A股经历了近三年的熊市，上证指数从3700点附近一路跌到2024年9月的2700点附近，随后在9月底启动一波急速行情。

**两种典型投资者的结局：**

| 投资者 | 策略 | 2022-2024.9表现 | 2024.9.24后表现 | 最终结局 |
|--------|------|------------------|-------------------|----------|
| 老王（越跌越买型） | "好公司越跌越买"，从2022年开始陆续加仓，到2024年中已满仓+部分融资 | 账面浮亏40-50%，融资盘面临平仓风险 | 行情来了，但融资盘在底部附近被强平，没等到反弹 | 永久性亏损，本金损失60%以上 |
| 老李（空仓等待型） | 2022年初清仓后保持80%现金，只在2022年底和2023年底小仓位抢过两次反弹，止损出局 | 账面几乎不亏不赚，现金充裕 | 9月底行情启动，分批加仓至60%仓位，抓住主升浪 | 本金增长40-50%，且全程心理稳定 |

**关键差异：**
- 老王在"敌之可胜"还没出现时就强行进攻（满仓+杠杆），违反"先为不可胜"
- 老李坚持"先为不可胜"（高现金+小仓位），等到"敌之可胜"出现（行情启动）才出击

**兵法依据：** "胜兵先胜而后求战，败兵先战而后求胜"——老李是先胜后战，老王是先战而后求胜。

### 2.3 风险管理的兵法清单

把风险管理动作整理成清单，对照执行：

| 兵法原则 | 风控动作 | 具体规则 | 兵法原文 |
|----------|----------|----------|----------|
| 先为不可胜 | 单笔止损 | 单笔亏损不超过总资金2% | "先为不可胜" |
| 不可胜在己 | 仓位上限 | 单只股票不超过总仓位20% | "不可胜在己" |
| 不可胜在己 | 现金储备 | 永远保持20%以上现金 | "不可胜在己" |
| 不可胜在己 | 禁用杠杆 | 严禁融资融券、场外配资 | "不可胜在己" |
| 以待敌之可胜 | 空仓等待 | 没有符合策略的机会就不开仓 | "以待敌之可胜" |
| 兵贵速不贵久 | 时间止损 | 超过预设持仓时间无盈利则退出 | "兵贵胜，不贵久" |
| 立于不败之地 | 分散配置 | 持仓3-5只，行业不相关 | "立于不败之地" |
| 不战而屈人之兵 | 预设条件单 | 用条件单替代手动止损 | "不战而屈人之兵" |

**自测：** 把这张表打印出来，对照自己最近10笔交易，逐笔打勾。能打全勾的有几笔？大多数散户能有3笔全勾就不错了。

## 三、趋势投资体系——"求之于势"

> **原文：** "善战者，求之于势，不责于人，故能择人而任势。"——《兵势篇》
>
> **原文：** "激水之疾，至于漂石者，势也。"——《兵势篇》

### 3.1 什么是"势"

> "激水之疾，至于漂石者，势也"——湍急的水流能把石头冲走，这就是"势"的力量。

**势，是合力的方向，是客观形成的趋势，它远超个人的力量。**

在股市里，"势"就是趋势。趋势是基本面、资金面、情绪面三者共振形成的合力。这个合力一旦形成，不会因为你的看法而改变。

**趋势的三层：**

1. **长期趋势**（月线、年级别）——由基本面决定，持续数年
2. **中期趋势**（周线级别）——由资金面+基本面共同决定，持续数月
3. **短期趋势**（日线级别）——由情绪面主导，持续数日到数周

**识别趋势的工具：**

| 工具 | 长期趋势 | 中期趋势 | 短期趋势 |
|------|----------|----------|----------|
| 均线系统 | 年线方向 | 周线MA20/60 | 日线MA5/10/20 |
| 价格结构 | 月线高低点抬高/降低 | 周线突破/回踩 | 日线形态 |
| 资金流向 | 北向年度净流入/流出 | 融资余额月度变化 | 龙虎榜、北向日度数据 |
| 量能关系 | 月线放量/缩量 | 周线量价配合 | 日线异动量 |

**关键认知：趋势不是预测出来的，是观察出来的。** 你不需要预测趋势会不会继续，你只需要观察趋势是否还在。

### 3.2 顺势 vs 逆势

#### 3.2.1 顺势——"求之于势"

**顺势交易的核心：** 上升趋势做多，下降趋势空仓或做空（A股做空工具有限，主要是空仓）。

**顺势的"求"字很关键**——是"借"势，不是"造"势。趋势已经形成，你借力跟随，不需要自己判断顶底。

**顺势交易的动作：**
1. 确认趋势形成（突破关键位、均线多头排列等）
2. 在趋势确认后第一次回调时介入
3. 趋势延续则持有，趋势破坏则退出
4. 不预测顶底，让市场告诉你什么时候结束

#### 3.2.2 逆势——"责于人"

**逆势交易的核心：** 抄底逃顶，靠个人判断对抗市场。

> "善战者，求之于势，**不责于人**"——善于作战的人依靠势，不苛求人。

逆势交易就是"责于人"——你认为自己比市场聪明，能抓到底、能逃掉顶。这是极端危险的。

**逆势交易的典型表现：**
- "已经跌了这么多了，应该到底了" → 抄底
- "涨了这么多了，应该到顶了" → 逃顶
- "这次不一样" → 在明显泡沫中追高

#### 3.2.3 实例：2024年9月底A股行情启动，顺势者 vs 抄底者

**背景：** 2024年9月24日起，A股在政策组合拳下启动急速行情，上证指数9个交易日从2750点附近涨到3600点附近，随后高位震荡回调。

**三种投资者的结局：**

| 投资者 | 策略 | 9.24前仓位 | 9.24-10.8操作 | 10.8后操作 | 最终结局 |
|--------|------|------------|----------------|------------|----------|
| 小A（顺势型） | 等趋势确认后跟进。9月底突破3000点后小仓试水，10月初回踩时加仓 | 0%（一直空仓） | 10月初加到40%仓位，成本约3200点 | 11月初跌破3400减仓到20%，保住大部分利润 | 盈利约15-20% |
| 小B（抄底型） | 2023年底就抄底，越跌越买 | 80%（深套中） | 行情来了回血，但成本太高，到3500点才解套 | 3500点刚解套，舍不得卖，又跌回去 | 几乎不赚不亏，浪费整波行情 |
| 小C（追涨型） | 10月8日开盘追高买入 | 0% | 10月8日开盘3670点全仓杀入 | 高位震荡被震出局，止损出局 | 亏损15-20% |

**关键差异：**
- 小A顺势，在趋势确认后介入，回踩加仓，回调减仓——**求之于势**
- 小B逆势抄底，深套后回血即解套，整波行情白忙——**责于人**（高估自己的抄底能力）
- 小C追高，在情绪最高点介入，成为接盘侠——**逆势且被情绪致于人**

**兵法依据：** "求之于势，不责于人"——小A是顺势者，小B和小C都是逆势者，结局天差地别。

### 3.3 造势与借势

#### 3.3.1 借势——跟随已形成的趋势

**借势的特征：**
- 趋势已经明确形成，市场有共识
- 风险较低，但收益也相对有限（错过了初段）
- 适合大多数投资者

**借势的时机：**
- 趋势确认后的第一次回调
- 突破重要阻力位后的回踩
- 均线多头排列后的缩量整理

#### 3.3.2 造势——在趋势将起未起时提前布局

**造势的特征：**
- 趋势尚未形成，但你判断大概率会形成
- 风险较高（判断错了就是逆势），但收益最大
- 需要更高的判断力和更大的勇气

**造势的时机：**
- 大级别底部区域，市场极度恐慌时
- 政策即将出台前的布局
- 行业拐点将出现但市场尚未反应

#### 3.3.3 实例：政策利好出台前布局（造势） vs 政策利好确认后跟进（借势）

**场景：** 假设市场预期2025年年中会有大规模刺激政策出台（虚构场景）。

**造势者（老张）：**
- 2025年3月开始研究可能受益的板块（地产链、消费、基建）
- 4月分批建仓，仓位30%，买入逻辑是"政策出台是大概率事件"
- 5月政策出台前再加仓到50%
- 6月政策落地，市场亢奋，老张在亢奋中分批减仓
- **风险：** 如果政策没出台或力度不及预期，要严格止损
- **收益：** 抓住整波行情，盈利40-60%
- **要求：** 对政策判断准确、仓位控制得当、纪律严明

**借势者（小赵）：**
- 5月政策出台后，等市场确认反应（突破关键位）才进场
- 6月初突破后回调时建仓，仓位40%
- 7-8月持有，趋势破坏后退出
- **风险：** 错过初段行情，且可能买在回调中
- **收益：** 抓住中段行情，盈利20-30%
- **要求：** 识别趋势、顺势执行

**两种策略的本质区别：**

| 维度 | 造势 | 借势 |
|------|------|------|
| 时机 | 趋势将起未起 | 趋势已起 |
| 难度 | 高（需要预判） | 中（只需识别） |
| 风险 | 高（判断错则逆势） | 低（趋势已确认） |
| 收益 | 高（抓住整波） | 中（抓住中段） |
| 适合人群 | 老手、有信息优势者 | 大多数投资者 |

**建议：** 大多数投资者应该以借势为主，造势为辅。造势需要的能力和资源远超普通散户。

## 四、仓位管理体系——"十则围之"

> **原文：** "故用兵之法，十则围之，五则攻之，倍则分之，敌则能战之，少则能逃之，不若则能避之。"——《谋攻篇》

这是孙子兵法对仓位管理最直接的指导。

### 4.1 兵力对比与仓位对应

孙子根据兵力对比给出六种策略，对应到交易，就是**根据确定性等级决定仓位大小**：

| 确定性等级 | 兵法策略 | 仓位建议 | 实例场景 |
|------------|----------|----------|----------|
| 极高确定性 | 十则围之 | 重仓（60-80%） | 政策+资金+技术三重共振，且基本面支撑 |
| 高确定性 | 五则攻之 | 大仓（40-60%） | 趋势明确+基本面支撑，无重大风险 |
| 较高确定性 | 倍则分之 | 中仓（20-40%）分批 | 趋势初步形成，需进一步确认 |
| 一般确定性 | 敌则能战之 | 小仓（10-20%） | 方向不明，小仓试水 |
| 低确定性 | 少则能逃之 | 极小仓或观望 | 信号矛盾，看不清方向 |
| 看不懂 | 不若则能避之 | 不参与 | 完全看不懂的行情 |

#### 4.1.1 极高确定性——"十则围之"

**特征：** 政策面、资金面、技术面、基本面四重共振，且无重大利空风险。

**实例：** 2024年9月底A股行情启动时，"政策组合拳+长期下跌后估值极低+技术面突破+资金面北向流入"四重共振，确定性极高。此时可以重仓指数ETF或确定性高的龙头股。

**注意：** 极高确定性场景极少出现，可能几年才一次。看到这种机会时要敢于重仓，但仍然要留20%以上现金。

#### 4.1.2 高确定性——"五则攻之"

**特征：** 趋势明确+基本面支撑，但缺少政策催化或资金面还不够强。

**实例：** 某只业绩优秀的消费股，长期上升趋势中，回调到年线附近，估值合理。此时可以大仓介入，止损设在年线下方。

**完整案例（虚构示例，非投资建议）：**

2024年5月，投资者小王看好某消费龙头。当前价80元，年线在75元，PE 25倍（近5年30%分位）。
- 基本面：ROE 20%+、连续10年分红、负债率30%、护城河稳固（品牌+渠道）
- 技术面：长期上升趋势中，回调到年线附近缩量企稳，量能萎缩至上月50%
- 资金面：北向资金近1月净流入5亿，机构持仓稳定
- 确定性评估：趋势尚未完全确认（缺放量突破信号）但基本面支撑强 → 高确定性（五则攻之）
- 仓位决策：40%仓位，分两批建仓
- 建仓计划：首批20%在80元建仓，第二批20%等放量站上85元后加仓
- 止损设定：止损位73元（年线下方2元），单笔最大亏损约8.75%（4万/40万仓位=总资金4%），略超2%硬规则 → 需调低仓位至30%（首批15%+二批15%）
- 止盈设定：第一目标95元（PE修复至30倍），第二目标110元（PE修复至35倍，分批退出）
- 兵法依据：五则攻之（高确定性大仓）+ 倍则分之（分批建仓）+ 先为不可胜（年线下方止损）

**关键认知：** 高确定性≠无风险，仍要严格执行2%单笔止损硬规则。当止损位过远导致单笔亏损超2%时，必须下调仓位而非放宽止损规则。

#### 4.1.3 较高确定性——"倍则分之"

**特征：** 趋势初步形成，但还需要进一步确认。此时分批建仓，留加仓和减仓的灵活性。

**实例：** 某只科技股突破长期下降趋势，但突破后还没回踩确认。此时可以先建20%底仓，回踩确认后加到30-40%。

**完整案例（虚构示例，非投资建议）：**

2024年8月，某科技股突破半年平台后未回踩，投资者老张想买但确定性不够。当前价15元，PE 40倍（偏高）。
- 基本面：订单增长50%+但盈利尚未兑现（产能爬坡中），行业景气度向上
- 技术面：突破半年平台14元有效，但突破后直接拉升无回踩确认，量能放大至上月2倍
- 资金面：龙虎榜有机构席位，但融资盘快速增加（需警惕短线游资介入）
- 确定性评估：趋势初步形成但缺回踩确认 + 基本面盈利未兑现 → 较高确定性（倍则分之）
- 仓位决策：20%底仓，分批建仓
- 建仓计划：首批10%在15元建仓（试水），等回踩到14元附近不破再加10%（确认后加仓）
- 止损设定：止损位13.5元（突破平台下方0.5元），单笔最大亏损10%（1.5万/15万仓位=总资金1.5%），符合2%硬规则
- 止盈设定：第一目标18元（量度涨幅），分批退出
- 退出逻辑：若跌破13.5元说明突破失败，立即止损；若回踩14元不破则加仓；若直接拉升不回踩则只持10%底仓不追高
- 兵法依据：倍则分之（分批建仓保留灵活性）+ 求之于势（顺势但等确认）+ 先为不可胜（硬止损）

**关键认知：** "倍则分之"的核心是"分"——分批建仓保留灵活性。即使判断错了，首批10%的亏损可控；判断对了，回踩确认后加仓10%摊低成本。如果直接追高一次性满仓，就违反了"分之"原则，回踩时无弹药加仓、判断错时无空间减仓。

#### 4.1.4 一般确定性——"敌则能战之"

**特征：** 方向不明，多空信号矛盾。此时小仓试水，主要是为了保持对市场的敏感度。

**实例：** 震荡市中，某只股票在区间内波动，方向不明。可以用10%仓位做高抛低吸，主要为了保持盘感。

#### 4.1.5 低确定性——"少则能逃之"

**特征：** 信号矛盾，看不清方向。此时极小仓或观望。

**实例：** 某只股票技术面看多、基本面看空，矛盾明显。此时观望，等矛盾解决再决策。

#### 4.1.6 看不懂——"不若则能避之"

**特征：** 完全看不懂的行情。**不参与。**

**实例：** 某只妖股连续涨停，但你完全看不懂炒作逻辑。不参与，即使它再涨10个板也不参与。

### 4.2 分批建仓的艺术

> **原文：** "倍则分之"——兵力是敌人两倍时，要分兵。

"分之"不仅是分兵进攻，在交易中更意味着**分批建仓**——不要一次性满仓，留出灵活性。

#### 4.2.1 为什么要分批

- **降低时点风险**：分批建仓可以平均成本，避免买在最高点
- **保留加仓能力**：分批意味着手里还有弹药，回调时可以加仓
- **保留减仓能力**：如果判断错了，分批建仓的部分可以先减仓
- **心理稳定**：分批建仓比一次性满仓心理压力小得多

#### 4.2.2 金字塔建仓法 vs 倒金字塔

**金字塔建仓法（推荐）：** 底部仓位大，越往上加仓越少。

```
        /\
       /  \        ← 第3次买：最少（涨了才加仓）
      /____\
     /      \      ← 第2次买：中等
    /________\
   /          \    ← 第1次买：最多（底仓最重）
  /____________\
```

像金字塔一样，底部宽顶部尖——第一次买最多，后面越涨加越少。

```
示例：总仓位目标40%

第一次建仓（趋势初步形成）：20%仓位
第二次加仓（回踩确认）：    12%仓位
第三次加仓（突破前高）：    8%仓位

总仓位：40%
平均成本：较低（因为大部分仓位在低位建）
```

**优点：**
- 大部分仓位在低位建，平均成本低
- 越涨加仓越少，避免高位重仓
- 即使最后一次加仓后回调，整体仍盈利

**倒金字塔建仓法（不推荐）：** 底部仓位小，越往上加仓越多。

```
示例：总仓位目标40%

第一次建仓：5%仓位
第二次加仓：12%仓位
第三次加仓：23%仓位

总仓位：40%
平均成本：较高（大部分仓位在高位建）
```

**缺点：**
- 大部分仓位在高位建，平均成本高
- 一旦回调，整体快速亏损
- 这是典型的"追涨加仓"，是散户亏钱的最常见模式

#### 4.2.3 实例：金字塔 vs 倒金字塔的优劣对比

**场景：** 某股票从10元开始上涨，目标位15元，过程中回调到11元、12元。

**金字塔建仓者（小张）：**
- 10元建仓20%，11元加仓12%，12元加仓8%
- 平均成本：10.6元
- 总仓位：40%
- 跌到10.6元才盈亏平衡，安全垫较厚
- 即使跌到11元，整体仍盈利

**倒金字塔建仓者（小王）：**
- 10元建仓5%，11元加仓12%，12元加仓23%
- 平均成本：11.6元
- 总仓位：40%
- 跌到11.6元就盈亏平衡，安全垫薄
- 跌到11元就已经亏损

**同样的总仓位、同样的标的，仅仅因为建仓顺序不同，成本差了1元（约10%）。** 这10%的差距，在熊市中就是生与死的差别。

**兵法依据：** "倍则分之"——分批建仓是兵法明确要求的。但分批的方向有讲究，**金字塔建仓才是顺势分兵，倒金字塔是逆势加仓，违反"求之于势"原则。**

## 五、交易心理体系——"致人而不致于人"

> **原文：** "善战者，致人而不致于人。"——《虚实篇》

**翻译：** 善于作战的人，**调动敌人而不被敌人调动**。

在交易中，**"敌人"就是市场情绪**。"致人而不致于人"意味着：**你的交易行为应该由你的计划决定，而不是由市场情绪决定。**

### 5.1 被市场"致于人"的典型表现

#### 5.1.1 FOMO追高（Fear of Missing Out）

**表现：** 看到股票大涨，怕踏空，忍不住追高买入。

**心理过程：**
```
股票大涨 → "再不买就来不及了" → 忽略计划 → 追高买入 → 高位被套
```

**致于人的本质：** 你的买入决策由"涨"这个市场行为驱动，而不是由你的研究计划驱动。

#### 5.1.2 恐慌割肉

**表现：** 一跌就慌，止损位形同虚设，跌5%就割肉。

**心理过程：**
```
股票下跌 → "完了，要崩了" → 忘记止损位 → 慌忙卖出 → 卖在低点
```

**致于人的本质：** 你的卖出决策由"跌"这个市场行为驱动，而不是由你的止损规则驱动。

#### 5.1.3 报复性交易

**表现：** 亏损后想立刻赚回来，加大仓位、加大频率。

**心理过程：**
```
亏损 → "我要赚回来" → 加大仓位 → 加大风险 → 更大亏损
```

**致于人的本质：** 你的交易决策由"亏损"这个结果驱动，而不是由市场机会驱动。

#### 5.1.4 锚定效应

**表现：** 执着于买入价，该卖不卖、该买不买。

**心理过程：**
```
股票从10元跌到8元 → "我要等到10元回本再卖" → 错过止损时机 → 跌到5元深套
```

**致于人的本质：** 你的交易决策由"买入价"这个无关变量驱动，而不是由标的当前价值驱动。

**买入价是过去的事，跟你现在该不该持有完全无关。** 这是交易中最难克服的心理偏差之一。

### 5.2 "致人"的做法

> "致人"——调动市场，而不是被市场调动。在交易中，体现为**按计划机械执行，不被情绪左右**。

#### 5.2.1 提前制定交易计划

**完整的交易计划必须包含：**

| 要素 | 内容 | 兵法依据 |
|------|------|----------|
| 标的 | 买什么 | "知己知彼" |
| 进场价 | 在什么价位买 | "始计篇"庙算 |
| 止损价 | 跌到什么价位卖 | "先为不可胜" |
| 止盈价 | 涨到什么价位卖 | "军形篇"先胜 |
| 仓位 | 买多少 | "十则围之" |
| 加仓条件 | 什么情况下加仓 | "倍则分之" |
| 减仓条件 | 什么情况下减仓 | "九变篇"应变 |
| 持仓时间 | 最长持有多久 | "兵贵速不贵久" |
| 退出逻辑 | 什么情况下逻辑证伪 | "用间篇"反馈 |

#### 5.2.2 按计划机械执行

**机械执行的核心：** 计划一旦制定，执行时不再思考。思考在事前，执行在事后。

**为什么不再思考？**
- 事中思考必然受情绪影响
- 事前思考是理性的，事中思考是感性的
- 让"理性的你"制定计划，让"机械的你"执行计划

#### 5.2.3 用条件单/程序化交易替代手动操作

**条件单的作用：**
- 提前设置好止损单、止盈单
- 价格触及条件时自动执行
- 避免"到价不舍得卖"的心理障碍

**程序化交易的作用：**
- 把交易策略写成程序，由程序执行
- 完全排除情绪干扰
- 适合有编程能力的投资者

#### 5.2.4 实例：同一个交易计划，手动执行 vs 条件单执行的结果差异

**场景：** 投资者计划买入某股票，10元买入，9.5元止损，11元止盈，仓位20%。

**手动执行者（小张）：**

| 时间 | 价格 | 计划 | 实际 | 偏离 |
|------|------|------|------|------|
| 买入日 | 10元 | 买入20% | 买入20% | 按计划 |
| 第3天 | 9.5元 | 止损 | "再等等，可能反弹" | 偏离 |
| 第5天 | 9元 | 已止损 | "现在卖亏更多" | 偏离 |
| 第7天 | 8.5元 | 已止损 | 恐慌卖出 | 严重偏离 |
| 结局 | - | 计划亏损1% | 实际亏损3% | 多亏2% |

**条件单执行者（小李）：**

| 时间 | 价格 | 计划 | 实际 | 偏离 |
|------|------|------|------|------|
| 买入日 | 10元 | 买入20% | 买入20% | 按计划 |
| 买入日 | 设置9.5止损单 | 设置 | 已设置 | 按计划 |
| 第3天 | 9.5元 | 止损 | 自动止损 | 按计划 |
| 结局 | - | 计划亏损1% | 实际亏损1% | 按计划 |

**同样的计划、同样的标的、同样的止损位，手动执行比条件单多亏2%。** 这2%就是"被情绪致于人"的代价。

**长期来看：** 假设一年20笔交易，每笔都被情绪影响2%，累计40%的差距。这就是大多数散户跑输指数的根本原因——不是研究能力差，是执行能力差。

### 5.3 情绪管理

> **原文：** "主不可以怒而兴师，将不可以愠而致战。合于利而动，不合于利而止。"——《火攻篇》

**翻译：** 君主不能因愤怒而发动战争，将领不能因怨恨而挑起战斗。**符合利益才行动，不符合利益就停止。**

这是交易情绪管理的最高原则：**情绪化时不交易。**

#### 5.3.1 三种情绪化状态及对策

**状态一：发怒时不交易**

**场景：** 你刚被某只股票"坑"了——业绩突然暴雷、停牌、闪崩。你很愤怒，想"赚回来"。

**对策：** 强制冷静期。**被坑后24小时内禁止开新仓。** 让愤怒过去，等理性回归。

**兵法依据：** "主不可以怒而兴师"——愤怒时的决策必然是错的。

**状态二：兴奋时不交易**

**场景：** 你刚大赚一笔，浮盈30%。你很兴奋，觉得"今天运气好，再加仓赚更多"。

**对策：** 大赚后48小时内禁止加仓。**让兴奋过去，避免过度自信。**

**兵法依据：** "将不可以愠而致战"——情绪激动时（无论愤怒还是兴奋）都不应该做决策。

**状态三：亏损后强制冷静期**

**场景：** 你连续亏损3笔，心态开始崩。

**对策：** **连续亏损3笔，停止交易1周。** 让心态恢复，期间只做研究、不做交易。

**为什么是3笔？** 2笔可能是运气不好，4笔可能已经心态崩了来不及刹车。3笔是最佳预警点。

#### 5.3.2 情绪管理清单

| 情绪状态 | 表现 | 对策 | 冷静期 |
|----------|------|------|--------|
| 愤怒 | 被坑后想报复 | 停止开新仓 | 24小时 |
| 兴奋 | 大赚后想加仓 | 停止加仓 | 48小时 |
| 连续亏损 | 心态崩溃 | 停止所有交易 | 1周 |
| 连续盈利 | 过度自信 | 减半仓位 | 1周 |
| 大跌后 | 恐慌 | 不看盘 | 24小时 |
| 大涨后 | 贪婪 | 不加仓 | 24小时 |

## 六、交易纪律——"将不听吾计，用之必败"

> **原文：** "将听吾计，用之必胜，留之；将不听吾计，用之必败，去之。"——《始计篇》

**翻译：** 将领听从我的计谋，用他就必胜，留下他；将领不听我的计谋，用他必败，撤掉他。

在交易中，**"将"就是你的执行力**。你的理性之计（交易计划）需要被执行之将（你的操作）落实。**如果你的情绪之将不听理性之计，必然失败。**

### 6.1 纪律为什么难执行

#### 6.1.1 人性弱点

| 弱点 | 在交易中的表现 | 兵法对应 |
|------|----------------|----------|
| 贪婪 | 该止盈不止盈，想赚更多 | "知止可以不殆" |
| 恐惧 | 该止损不止损，怕卖了就涨 | "先为不可胜" |
| 侥幸 | "再等等可能就好了" | "先胜后战" |
| 自负 | "这次不一样" | "知己知彼" |
| 从众 | 别人买什么我买什么 | "避实击虚" |
| 急躁 | 没有机会硬找机会 | "以待敌之可胜" |

#### 6.1.2 "将不听吾计"的典型场景

**场景：** 你计划某股票9.5元止损。

```
跌到9.5元 → 理性之计：卖出 → 情绪之将："再等等，可能反弹"
跌到9.0元 → 理性之计：早该卖了 → 情绪之将："现在卖亏更多"
跌到8.5元 → 理性之计：必须卖 → 情绪之将："已经这样了，再等等"
跌到8.0元 → 理性之计：无解 → 情绪之将：恐慌卖出
最终：深套，亏15%出场，比计划多亏13%
```

**这就是"将不听吾计，用之必败"——你的情绪之将不听理性之计，导致必败。**

### 6.2 提高纪律执行力的方法

#### 6.2.1 方法一：交易计划写下来

**为什么写下来有效？**
- 写下来是"理性之你"在表达
- 白纸黑字比脑子里想更有约束力
- 偏离计划时，写下来的计划会让你意识到偏离

**操作：** 每笔交易开仓前，在交易日志中写下完整计划（见6.3模板）。没写计划就不开仓。

#### 6.2.2 方法二：用条件单替代手动操作

**条件单的种类：**
- **止损单**：价格触及止损位自动卖出
- **止盈单**：价格触及止盈位自动卖出
- **条件单**：满足特定条件（如突破、回踩）自动触发

**为什么条件单有效？**
- 排除情绪干扰
- 24小时自动监控，不需要盯盘
- 触发即执行，不会"再等等"

#### 6.2.3 方法三：交易日志

**交易日志的作用：**
- 强制你在事前思考（写日志时必须想清楚为什么买）
- 帮助你事后复盘（偏离计划的原因是什么）
- 长期积累形成自己的"战例库"

#### 6.2.4 方法四：定期复盘

**复盘的频率：**
- **每周复盘**：本周交易是否符合计划？纪律执行情况？
- **每月复盘**：本月盈亏归因？哪些策略有效、哪些无效？
- **每季度复盘**：策略是否需要调整？风险管理规则是否需要更新？

**复盘的内容：**
- 计划执行率：按计划执行的比例
- 偏离原因分析：为什么偏离？情绪？信息？判断？
- 盈亏归因：盈利来自哪些交易？亏损来自哪些交易？
- 策略调整：哪些规则需要加强、修改、放弃？

#### 6.2.5 方法五：外部监督

**为什么需要外部监督？**
- 自我监督容易被情绪突破
- 外部监督有"面子"压力
- 同伴可以提供客观视角

**外部监督的方式：**
- 找一个交易伙伴，互相监督纪律执行
- 在社群里公开自己的交易计划（接受他人监督）
- 加入交易教练或导师的辅导计划

### 6.3 交易日志模板

刚开始记日志不用搞那么复杂，先养成习惯最重要。下面是"新手必填5栏"简化版：

| 日期 | 买了什么 | 为什么买 | 止损线 | 今天心情 |
|------|---------|---------|--------|---------|
| 2026-XX-XX | 某ETF（510300） | 政策利好+估值低 | 3.65元 | 平静 |
| 2026-XX-XX | ... | ... | ... | ... |

刚开始记录只需要这5栏，养成习惯后再加更多字段。

等你坚持记了10笔以上，再升级到下面的完整版：

```
====================================
交易日志 #编号
====================================

【基本信息】
日期：YYYY-MM-DD
标的：
方向：买入/卖出
价格：
仓位：% of 总资金

【事前·庙算】
决策理由（兵法依据）：
  - 知彼：基本面/技术面/资金面研究结论
  - 知己：风险承受、能力圈、情绪状态
  - 五事评估：道（逻辑）天（周期）地（基本面）将（资金）法（纪律）
  - 确定性等级：极高/高/较高/一般/低/看不懂
  - 对应兵法策略：十则围之/五则攻之/倍则分之/敌则能战之/少则能逃之/不若则能避之

止损位：
止盈位：
持仓时间上限：
加仓条件：
减仓条件：
退出逻辑（什么情况下逻辑证伪）：

【事中·执行】
执行情况：按计划/偏离计划
偏离原因（如有）：
  - 情绪因素：愤怒/兴奋/恐惧/贪婪/侥幸
  - 信息因素：新信息出现，调整计划
  - 判断因素：原判断有误

【事后·复盘】
实际退出价：
实际盈亏：% 
盈亏归因：
  - 盈利交易：赚的是什么钱？逻辑兑现还是运气？
  - 亏损交易：亏在哪里？计划错了还是执行错了？
纪律执行评分（1-10）：
经验提炼（一句话）：

====================================
```

**使用方法：**
1. 开仓前填好"事前·庙算"部分
2. 持仓中如有偏离，填"事中·执行"部分
3. 退出后填"事后·复盘"部分
4. 每周复盘时翻看本周所有日志

**填写范例（虚构示例，非投资建议）：**

```
====================================
交易日志 #2024-010
====================================

【基本信息】
日期：2024-10-10
标的：沪深300ETF（510300）
方向：买入
价格：3.85元
仓位：20万（20% of 100万总资金）

【事前·庙算】
决策理由（兵法依据）：
  - 知彼：基本面（指数PE近5年25%分位，估值合理）；技术面（站上60日均线，MACD金叉）；资金面（北向资金近1月净流入80亿）
  - 知己：风险承受能力20%回撤，能力圈在宽基ETF，情绪状态稳定
  - 五事评估：道（政策利好确认=天时）7分，天（震荡市）6分，地（估值合理）7分，将（ETF在能力圈）8分，法（纪律严明）8分，综合7/10
  - 确定性等级：较高（趋势初步形成+政策催化+估值合理）
  - 对应兵法策略：倍则分之（中仓分批，首批20%）

止损位：3.65元（-5.2%，亏损约1万，单笔亏损1%总资金）
止盈位：4.30元（+11.7%）
持仓时间上限：3个月
加仓条件：放量突破3.95元且站稳3日，加仓10%
减仓条件：跌破3.75元减仓一半
退出逻辑：逻辑证伪——政策面转向或跌破60日均线

【事中·执行】
执行情况：按计划买入
偏离原因：无
  - 情绪因素：无（按条件单挂单等待，未盯盘）
  - 信息因素：无
  - 判断因素：无

【事后·复盘】（一周后更新）
实际退出价：未退出，仍在持仓
实际盈亏：浮盈约5.2%（10月17日涨到4.05元）
盈亏归因：
  - 浮盈来自政策利好推动+估值修复+顺势执行
  - 入场点合理，但仓位可以分两批建仓更稳妥（首批15%+确认后5%）
纪律执行评分：8/10
经验提炼：震荡市中分批建仓比一次性建仓更稳妥，未来类似场景应严格执行"倍则分之"

【持仓中调整记录】
- 2024-10-17：涨到4.05元，上移止损到3.85元（保本止损，符合"先为不可胜"）
- 后续跟踪：若涨到4.30元，分批减仓（第一批减10万，第二批等4.50元全部退出）

====================================
```

**范例要点：**
- 每个字段都有具体数字和内容，不能空着或写"差不多"
- 决策理由必须标注兵法依据，强制用兵法框架思考
- 止损位是绝对数（3.65元）而不是模糊描述（"看情况止损"）
- 持仓中要根据价格变化动态调整止损位（保本止损、移动止损）
- 复盘部分不写"还行""不错"，要具体到分数和经验提炼

## 七、避实击虚——寻找市场盲区

> **原文：** "夫兵形象水，水之形避高而趋下，兵之形避实而击虚。"——《虚实篇》
>
> **原文：** "兵之所加，如以碫投卵者，虚实是也。"——《虚实篇》

**翻译：** 兵的形象像水，水避高而趋下，兵避实而击虚。军队攻击敌人，如同用石头砸鸡蛋，关键在于避实击虚。

**一句话理解：市场的"实"是共识，"虚"是盲区。** 避开大家都在挤的共识，去找没人注意的盲区。

比如：大家都在追AI芯片=共识（实）；没人注意的环保设备=盲区（虚）。再比如：大家都在买大盘蓝筹=共识（实）；被忽略的小盘细分龙头=盲区（虚）。

### 7.1 什么是"实"（避开的地方）

"实"是市场共识强烈、估值已经反映预期、风险大于收益的地方。**"实"的地方不要去。**

#### 7.1.1 热门板块高潮期

**特征：**
- 所有人都在讨论（出租车司机都在聊）
- 估值远超历史区间（PE在历史95%分位以上）
- 媒体头条天天报道
- 新基金扎堆发行

**为什么避开？**
- 共识太强 = 没有预期差
- 估值已经反映所有利好，任何不及预期都是利空
- 一旦情绪转向，踩踏式下跌

**实例：** 2021年初的白酒板块、2021年中的新能源板块、2023年的AI板块，都是"实"的典型。在高潮期追入者，多数深套至今。

**完整案例（虚构示例，非投资建议）：**

2021年2月，投资者老刘看到白酒板块连涨2年，某白酒龙头从200元涨到320元，PE达70倍（历史98%分位），所有人都在讨论"核心资产永远涨"。老刘在320元满仓追入。随后板块见顶，2024年初跌到120元，亏损62%。这就是击"实"——在最拥挤的交易中接了最后一棒。

**复盘拆解：**
- 拥挤度：PE历史98%分位 + 全民讨论 + "核心资产永远涨"共识 = 最拥挤的交易
- 估值风险：70倍PE已透支未来5-10年增长，任何不及预期都是利空
- 行为特征：老刘满仓追入，违反"先为不可胜"（无现金储备）和"倍则分之"（一次性满仓）
- 兵法依据：违反"避实击虚"——在"实"处重仓进攻，必然被深套

**正确的避实做法：** 2021年2月白酒板块PE达历史98%分位时，应识别为"实"——降低仓位或离场，转而寻找被市场忽视的"虚"处（如当时低估值银行、煤炭）。

#### 7.1.2 连板妖股高位

**特征：**
- 短期翻倍以上涨幅
- 连续涨停
- 成交量极度放大
- 龙虎榜全是游资

**为什么避开？**
- 完全情绪驱动，没有基本面支撑
- 高位随时崩塌，连续跌停无法卖出
- "击鼓传花"游戏的最后一棒

#### 7.1.3 大众共识一致的品种

**特征：**
- 券商研报一致看多
- 财经媒体一致唱好
- 投资者交流群一致看好

**为什么避开？**
- 共识 = 没有预期差
- 共识意味着所有买家都已经买入，没有新增买盘
- 一致看多是见顶信号，一致看空是见底信号

### 7.2 什么是"虚"（攻击的地方）

"虚"是被市场忽视、估值未反映预期、风险收益比有利的地方。**"虚"的地方才是机会。**

#### 7.2.1 被忽视的行业

**特征：**
- 低关注度（机构持仓少、研报覆盖少、媒体报道少）
- 低估值（PE、PB在历史低位）
- 基本面正在改善（行业拐点、政策利好）

**为什么是机会？**
- 关注度低 = 持有者少 = 潜在买盘大
- 估值低 = 安全边际高
- 基本面改善 = 催化剂存在

#### 7.2.2 预期差

**特征：** 市场预期很低，但实际可能超预期。

**为什么是机会？**
- 股价反映的是预期，不是现实
- 预期低 = 股价低
- 实际超预期 = 股价大涨

**预期差的来源：**
- 市场对政策力度低估
- 市场对行业拐点判断错误
- 市场对公司业绩预期过低

#### 7.2.3 冷门但有催化剂的标的

**特征：**
- 冷门（关注度低、估值低）
- 有明确催化剂（资产注入、新产品、政策受益）

**为什么是机会？**
- 冷门 = 估值低
- 催化剂 = 上涨动力
- 催化剂兑现时，关注度快速提升，估值和业绩双升

#### 7.2.4 实例：2024年初的高股息蓝筹

**背景：** 2024年初，A股高股息蓝筹（银行、煤炭、电力等）长期被市场忽视，估值极低（PE普遍在5倍以下，股息率5-8%），市场主流资金追逐AI、消费等热门赛道。

**"虚"的特征：**
- 低关注度：机构低配、研报覆盖少
- 低估值：PE历史低位、股息率历史高位
- 基本面改善：利率下行周期中，高股息资产的吸引力提升

**催化剂：**
- 2024年市场下跌中，高股息板块抗跌，吸引避险资金
- "中特估"政策持续推进
- 长期资金（保险、社保）配置需求

**结果：** 2024年上半年，高股息蓝筹成为少数上涨的板块，大幅跑赢市场。

**兵法依据：** "避实而击虚"——避开当时被热炒的AI（实），攻击被忽视的高股息（虚）。

**完整买卖案例（虚构示例，非投资建议）：**

2024年1月，投资者小陈注意到某煤炭股PE仅4.5倍、股息率8.2%、机构持仓处于5年最低点，市场无人讨论。按"避实击虚"原则，在5.2元建仓30%仓位。3个月后中特估行情启动，煤炭板块成为主线，小陈在7.8元减仓退出，获利50%。这就是击"虚"——在被忽视的地方找到预期差。

**完整复盘拆解：**
- "虚"的识别：PE 4.5倍（历史5%分位以下）+ 股息率8.2%（远超10年期国债）+ 机构5年最低持仓 + 市场无人讨论 = 典型"虚"
- 仓位决策：高股息+低估值+基本面稳定 → 较高确定性 → "倍则分之" → 30%仓位，符合"五则攻之"与"倍则分之"之间
- 止损设定：止损位设在4.8元（约-7.7%，对应单笔亏损约2.3%总资金），符合"先为不可胜"
- 退出决策：3个月内上涨50%，PE修复到7倍左右，股息率降至5.5%，估值不再极端 → 分批减仓而非一次性清仓
- 兵法依据：避实击虚（避开热门AI，攻击冷门煤炭）+ 先胜后战（事前设好止损仓位）+ 求之于势（趋势启动后顺势持有）

**关键认知：** "虚"的标的同样要按完整交易流程七步操作——避实击虚解决"买什么"，仓位管理解决"买多少"，止损止盈解决"怎么退"。仅识别"虚"不够，还要有完整的执行纪律。

**注意：** "虚"不是"差"，**"虚"是"被低估的好东西"**。这是避实击虚与垃圾股投机的根本区别。

### 7.3 避实击虚的实操要点

| 维度 | 实（避开） | 虚（攻击） |
|------|------------|------------|
| 关注度 | 极高 | 极低 |
| 估值 | 历史高位 | 历史低位 |
| 共识 | 一致看多 | 一致看空或无共识 |
| 催化剂 | 已兑现 | 尚未兑现 |
| 风险收益比 | 风险>收益 | 收益>风险 |
| 持有者结构 | 散户为主 | 机构为主或无人问津 |
| 量化判断 | PE历史分位>80%+机构超配+热搜霸榜=实 | PE历史分位<20%+机构低配+无人讨论=虚 |

**避实击虚的反向思考：** 当所有人都在说某个机会时，问自己"现在买入的对手是谁？为什么有人愿意卖给我？" 如果答不上来，你就是那个被击的"实"。

## 八、完整交易流程的兵法化

将一笔完整交易从研究到退出，用兵法框架串联。这是本阶的核心总结，也是"会用兵法"的最终检验。

```
第一步·庙算（始计篇）
├── 五事评估
│   ├── 道（逻辑）：买入逻辑是什么？是否符合大趋势？
│   ├── 天（周期）：当前处于什么周期？牛熊？行业景气？
│   ├── 地（基本面）：公司财务、护城河、估值如何？
│   ├── 将（能力圈）：这只股票我看看得懂？
│   └── 法（纪律）：我的纪律能否执行？
├── 七计对比
│   ├── 确定性够不够？（极高/高/较高/一般/低/看不懂）
│   ├── 风险收益比好吗？（潜在收益/潜在风险 > 2:1？）
│   └── 机会成本如何？（比手里其他标的好吗？）
└── 决策：做不做？
    ├── 不做：进入观察池，继续等
    └── 做：进入第二步

第二步·先胜后战（军形篇）
├── 风控预案
│   ├── 止损位：技术止损/金额止损/逻辑止损，取最严
│   ├── 仓位上限：单只不超过20%
│   └── 时间止损：最长持仓时间
├── 条件确认
│   ├── 趋势是否确认？（突破/回踩/均线排列）
│   ├── 信号是否共振？（技术面+基本面+资金面）
│   └── 时机是否合适？（不在亢奋时追，在回调时买）
└── 决策：什么时候做？
    ├── 立刻：进入第三步
    └── 等待：设触发条件，等条件满足再做

第三步·部署兵力（谋攻篇）
├── 确定性评估
│   ├── 十则围之：重仓（60-80%）
│   ├── 五则攻之：大仓（40-60%）
│   ├── 倍则分之：中仓（20-40%）分批
│   ├── 敌则能战之：小仓（10-20%）
│   ├── 少则能逃之：极小仓或观望
│   └── 不若则能避之：不参与
├── 分批计划
│   ├── 金字塔建仓：底大顶小
│   ├── 建仓节奏：分2-3次
│   └── 加仓条件：明确什么情况下加仓
└── 决策：做多少？
    └── 按确定性决定仓位，按金字塔原则分批

第四步·执行交易（兵势篇+虚实篇）
├── 顺势而为
│   ├── 在趋势确认后行动
│   ├── 上升趋势做多，下降趋势空仓
│   └── 不预测顶底，让市场告诉你
├── 避实击虚
│   ├── 不在亢奋时追，在回调时买
│   ├── 不买热门高潮期，买冷门拐点期
│   └── 不买共识一致，买预期差
├── 致人不致于人
│   ├── 按计划执行，不被情绪左右
│   ├── 用条件单替代手动操作
│   └── 不因涨跌改变计划
└── 执行：买入

第五步·持仓管理（九变篇）
├── 持续跟踪
│   ├── 逻辑是否变化？（行业、公司、政策）
│   ├── 趋势是否延续？（技术面信号）
│   └── 风险是否变化？（仓位、相关性）
├── 灵活调整
│   ├── 加仓：逻辑兑现且趋势延续
│   ├── 减仓：逻辑弱化或趋势破坏
│   └── 持有：逻辑和趋势都未变
├── 应变
│   ├── 市场变了策略也要变
│   ├── 不死扛，不固执
│   └── "将在外，君命有所不受"——根据实际情况调整
└── 持有：按计划管理

第六步·退出（作战篇+火攻篇）
├── 止盈
│   ├── 达到目标价分批退出
│   ├── 趋势破坏全部退出
│   └── 逻辑兑现后退出
├── 止损
│   ├── 跌破止损位机械执行
│   ├── 逻辑证伪立即退出
│   └── 不抱侥幸，不"再等等"
├── 时间止损
│   ├── 超时无预期收益则退出
│   └── "兵贵速不贵久"——资金有时间成本
├── 不因情绪退出
│   ├── 不因恐惧早卖（计划未触发不卖）
│   ├── 不因贪婪不卖（计划触发必卖）
│   └── 不因锚定不卖（买入价与退出无关）
└── 退出：卖出

第七步·复盘（用间篇）
├── 记录结果
│   ├── 填写交易日志"事后·复盘"部分
│   ├── 记录实际盈亏
│   └── 记录纪律执行情况
├── 分析得失
│   ├── 盈利交易：赚的是什么钱？逻辑兑现还是运气？
│   ├── 亏损交易：亏在哪里？计划错了还是执行错了？
│   └── 偏离计划：情绪因素还是信息因素？
├── 更新策略
│   ├── 哪些规则需要加强？
│   ├── 哪些规则需要修改？
│   └── 哪些规则需要放弃？
└── 为下一次"庙算"积累情报
    ├── 这次交易的经验是什么？
    ├── 类似标的下次遇到怎么做？
    └── 自己的情绪弱点又是什么？
```

### 8.1 完整交易流程实例

**场景：** 2024年9月底，投资者小李（前面提到的顺势者）面对A股急速行情，按完整交易流程操作。

**第一步·庙算：**
- 道：政策组合拳出台，做多逻辑明确
- 天：长期下跌后估值极低，周期底部反转可能
- 地：上证指数PE在历史10%分位以下，安全边际高
- 将：自己擅长指数ETF交易，在能力圈内
- 法：纪律执行能力强，能严格止损
- 七计：确定性极高（政策+估值+技术三重共振），风险收益比极佳
- 决策：做

**第二步·先胜后战：**
- 风控：止损设在突破位下方（约2900点），单笔止损2%
- 条件：突破3000点确认趋势，回踩不破2900点
- 决策：等突破后回踩时介入

**第三步·部署兵力：**
- 确定性：极高 → 十则围之 → 重仓
- 但考虑到行情急速、波动大，实际仓位控制在40%（保留加仓空间）
- 分批：分2次建仓，回踩时第一次20%，确认后第二次20%

**第四步·执行：**
- 顺势：突破3000点后回调到3100点附近介入
- 避实：不追10月8日开盘的高点，等回调
- 致人：用条件单设好止损，不被情绪左右

**第五步·持仓管理：**
- 持续跟踪：政策面持续利好，趋势延续
- 灵活调整：11月初跌破3400减仓到20%，保住利润
- 应变：行情从急速上涨转为震荡，策略相应调整

**第六步·退出：**
- 止盈：分批退出，第一次3400减半，第二次3500全部退出
- 时间止损：未触发
- 不因情绪退出：不因"还能涨更多"而持有，不因"已经跌了"而早卖

**第七步·复盘：**
- 记录：填写交易日志
- 分析：盈利来自政策催化+估值修复+顺势执行
- 更新：突破后回踩的入场模式有效，保留
- 经验：急速行情中仓位不必一次打满，留空间应对波动

**最终结果：** 盈利约15-20%，全程心理稳定，纪律执行到位。

**兵法依据：** 完整交易流程七步，每一步都有兵法依据，每一步都按计划执行。这就是"先胜后战"——胜利在开仓前就已经决定了。

## 九、兵法用于工作（学校场景版）

兵法不只用在股市。其实你每天在学校里也在"打仗"——和作业打、和考试打、和同学打、和老师打。这一节就用初中生能听懂的学校场景，把兵法搬到教室里。

### 案例1：小组作业分工——"将之道"和"法者"

- **场景：** 老师布置了一个小组课题，5人一组，两周内交一份报告。
- **兵法原理：** "将者，智信仁勇严"——选对组长；"法者，曲制官道主用"——明确分工和规则。
- **怎么做：** 先选一个能服众、会协调的组长（不一定成绩最好，但要会管人）；然后按特长分工——会查资料的查资料、会写文案的写文案、会做PPT的做PPT，每人职责写到纸上、定好截止日期。
- **一句话总结：** 选对人+定好规矩，比一群人闷头干强十倍。

### 案例2：期末考试复习安排——"先胜后战"

- **场景：** 还有1个月期末考试，6门课要复习。
- **兵法原理：** "胜兵先胜而后求战"——胜利在开打前就准备好了。
- **怎么做：** 提前3周列好复习表：哪一周复习哪几章、每天哪个时段做哪门、薄弱科目多分配时间。按表执行，每天打勾。不要考前一周才开始熬夜——那叫"先战而后求胜"，败兵的做法。
- **一句话总结：** 临时抱佛脚=先战后求胜，提前规划=先胜后战。

### 案例3：和同学竞争班干部——"知己知彼"

- **场景：** 你想竞选班长，对手是成绩比你好、人缘也不差的小明。
- **兵法原理：** "知己知彼，百战不殆"——了解自己的优势，也了解对手的弱点。
- **怎么做：** 先列自己的优势（比如组织活动多、和后排同学关系好），再列小明的弱项（比如很少和后排同学打交道、做事不够细致）。竞选演讲时重点突出"我会帮每个人解决问题"，而不是比成绩。
- **一句话总结：** 别拿自己的弱项去拼对手的强项，找对手的虚、用你的实。

### 案例4：面对不喜欢的老师——"致人而不致于人"

- **场景：** 数学老师讲课风格你不喜欢，一上他课就走神。
- **兵法原理：** "善战者，致人而不致于人"——主动调动局势，不被局势拖着走。
- **怎么做：** 不要被动忍受。主动找对策：课前先预习课本、课后找同学讨论、不懂的去问其他老师或网上找视频。把"被动听不懂"变成"主动补上来"。
- **一句话总结：** 你改变不了老师，但可以改变自己怎么学——别让老师决定你的成绩。

### 案例5：班级活动策划——"上下同欲者胜"

- **场景：** 班级要组织一次春游，但大家意见不统一，有人想去爬山、有人想去公园。
- **兵法原理：** "上下同欲者胜"——大家目标一致才能赢。
- **怎么做：** 别一上来就拍板。先开个班会让每个人说想法，找出"大家都勉强能接受"的方案（比如公园里有小山可以爬）。投票前先沟通，让少数派也觉得被尊重。
- **一句话总结：** 强行拍板=怨气满满，统一思想=全员开心。

## 十、兵法用于生活（日常场景版）

生活里到处是"小战场"。这一节用初中生的日常场景，看兵法怎么帮你化解烦恼。

### 案例1：和同学产生矛盾——"不战而屈人之兵"

- **场景：** 同桌借了你的橡皮没还，还理直气壮说"不就是一块橡皮吗"。
- **兵法原理：** "不战而屈人之兵，善之善者也"——不打架就赢，才是最高明的赢。
- **怎么做：** 别当场吵架。冷静说："橡皮是小事，但你借东西不还让我以后不敢借你别的，这个我比较在意。明天还我就行。" 给对方台阶下，但把道理讲清楚——既拿回橡皮，又让对方记住下次要还。
- **一句话总结：** 吵架赢了一时，关系坏了长久；用智慧化解才是真赢。

### 案例2：零花钱怎么花——"非利不动"

- **场景：** 同学都在买新出的盲盒/卡牌，你也心动了，但零花钱有限。
- **兵法原理：** "合于利而动，不合于利而止"——不符合自己利益的消费不动。
- **怎么做：** 先问自己三问：买了能玩多久？不买会难受几天？这笔钱花在别处更值吗？如果答案是"玩两天就腻、不买过两天就忘、钱攒着买书更值"，那就不买。
- **一句话总结：** 别人买 ≠ 你该买；花钱前先算"利"。

### 案例3：选择社团——"避实击虚"

- **场景：** 学校社团招新，篮球社、动漫社挤满了人，植物社、围棋社门可罗雀。
- **兵法原理：** "避实而击虚"——避开拥挤的地方，找冷门但适合自己的。
- **怎么做：** 别盲从挤热门。想想自己真的喜欢什么、有没有天赋。如果你喜欢安静、爱思考，去围棋社反而能当主力、被重视；挤进篮球社可能只是"陪练"。
- **一句话总结：** 热门的不一定适合你，冷门的反而更容易出头。

### 案例4：被同学激怒时——"怒不兴师"

- **场景：** 同学说了一句难听的话，你当场就想怼回去。
- **兵法原理：** "主不可以怒而兴师"——愤怒时做的决定一定是错的。
- **怎么做：** 强制冷静——先离开现场，去洗手间洗个脸，或者出去走一圈。**24小时后再决定怎么回应。** 大多数情况下，睡一觉你会发现"根本不值得生气"，或者想出比怼回去更高明的回应。
- **一句话总结：** 怒上头时闭嘴，冷静后开口——一句话能成事也能败事。

### 案例5：考试没考好想放弃——"胜不骄败不馁"

- **场景：** 这次月考数学考砸了，觉得自己不是学数学的料。
- **兵法原理：** "胜可知，而不可为"——一次结果不决定最终胜负，关键是从中学习。
- **怎么做：** 别急着否定自己。把卷子拿出来，分三类：会做但粗心错的、知识点没掌握的、完全看不懂的。前两类是"可以攻下的"，第三类找老师或同学补。一次考试只是"一仗"，不是"整场战争"。
- **一句话总结：** 一仗输了不等于整场战争输了——复盘、调整、再战。

## 十一、本阶练习与自测

### 9.1 思考题

#### 题目一
回顾你最大的一笔亏损，对照"完整交易流程"七步，你在哪一步犯了错？是庙算不清、先胜后战没做、兵力部署错误、执行被情绪左右、持仓管理失当、退出犹豫不决，还是复盘不到位？

**答题要求：**
- 详细描述这笔亏损的标的、时间、金额、过程
- 逐步对照七步框架，找出每一步的问题
- 总结：如果重做一次，你会怎么做？

#### 题目二
"先为不可胜"和"追求收益"矛盾吗？如何平衡？

**答题要求：**
- 解释"先为不可胜"的含义
- 解释"追求收益"的含义
- 分析两者是否矛盾，为什么不矛盾
- 给出平衡的具体方法

#### 题目三
你的"能力圈"边界在哪里？举一个你看不懂的标的例子。

**答题要求：**
- 列出你能力圈内的行业/类型（3-5个）
- 列出你能力圈外的行业/类型（3-5个）
- 举一个具体标的，说明为什么它在你能力圈外
- 承诺：能力圈外的标的，再好的机会也不参与

### 9.2 实操练习

#### 练习一：完整交易计划
选一只你关注但还没买入的股票，用"庙算+先胜后战"框架做一份完整的交易计划。

**要求：**
- 完成五事评估
- 完成七计对比
- 确定确定性等级和对应仓位
- 设定止损位、止盈位、持仓时间上限
- 制定分批建仓计划
- 制定退出逻辑

#### 练习二：交易日志回顾
回顾过去5笔交易，填写交易日志模板，分析纪律执行情况。

**要求：**
- 每笔交易填写完整日志（事前、事中、事后）
- 统计纪律执行率（按计划执行的比例）
- 分析偏离原因（情绪/信息/判断）
- 总结经验教训

#### 练习三：写下你的3条铁律
写下你的3条"铁律"——无论发生什么都不会违背的交易规则。

**示例：**
1. 单笔亏损不超过总资金2%，无条件止损
2. 单只股票不超过总仓位20%，永不加杠杆
3. 连续亏损3笔停止交易1周，强制冷静

**要求：**
- 铁律必须具体、可执行
- 铁律必须针对你自己的弱点
- 铁律必须可以客观判断是否违反

### 9.3 自测清单

完成以下自测，全部打勾才算通过本阶：

- [ ] 我有明确的风险管理规则并严格执行
- [ ] 我能区分"看懂"和"看不懂"的标的
- [ ] 我有书面的交易计划模板
- [ ] 我能识别自己被情绪控制的时刻
- [ ] 我有交易日志并在定期复盘
- [ ] 我理解仓位大小应该由确定性决定
- [ ] 我能在没有机会时空仓等待
- [ ] 我能按计划止盈止损，不因情绪偏离
- [ ] 我理解"先为不可胜"的含义并有具体动作
- [ ] 我能用"避实击虚"识别市场机会
- [ ] 我有至少3条铁律并坚持执行
- [ ] 我能用完整交易流程七步做一次完整决策

**通过标准：** 12项中至少10项打勾，且第1、4、8项必须打勾（这三项是底线）。

**未通过怎么办：** 回到对应章节重新学习，并用模拟盘练习至少20笔交易后再自测。

## 十二、本阶小结

### 10.1 核心要点回顾

| 兵法原则 | 交易应用 | 关键动作 |
|----------|----------|----------|
| 知己知彼 | 选股研究体系 | 基本面+技术面+资金面研究，能力圈识别 |
| 先为不可胜 | 风险管理体系 | 止损、仓位控制、分散、现金储备 |
| 求之于势 | 趋势投资体系 | 顺势交易，不逆势抄底逃顶 |
| 十则围之 | 仓位管理体系 | 按确定性定仓位，金字塔建仓 |
| 致人不致于人 | 交易心理体系 | 按计划执行，条件单替代手动 |
| 将不听吾计必败 | 交易纪律 | 交易日志、复盘、外部监督 |
| 避实击虚 | 寻找市场盲区 | 避开热门高潮，关注冷门拐点 |

### 10.2 一句话总结

> **兵法不教你赚钱，教你的是怎么不亏钱。不亏了，赚钱是早晚的事。**
>
> **一笔交易的结局，在按下买入键之前就已经决定了。**
>
> **先胜后战，胜利在开打之前就已成定局。**
