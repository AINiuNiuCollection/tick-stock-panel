# 《孙子兵法》系统教学总纲

> **写给你的话：**
>
> 你可能觉得孙子兵法跟自己没关系——又不上战场。但其实，你每天都在"打仗"：考试排名是战场，和同学的关系是战场，选什么社团也是战场。这本2500年前的书，教的不是怎么挥刀弄枪，而是怎么在复杂局面中做出最聪明的选择。读完它，你会发现——学习、交友、甚至将来炒股，都是同一个道理。

> **教学目标：** 从零基础到真正能将《孙子兵法》思维融入日常决策与股市投资实践。
>
> **教学理念：** 不背诵、不玄学、不空谈。每一条原理都必须能落地为一个具体的决策动作。

---

## 一、为什么学《孙子兵法》

### 1.1 它不是兵书，是决策学

《孙子兵法》表面讲战争，本质讲的是**不确定环境下的最优决策方法**。说白了，就是教你在不知道结果会怎样的情况下，怎么做出最聪明的选择。比如选文科还是理科、周末先写作业还是先打游戏、压岁钱存银行还是买基金——这些都是"决策"。战争是人类面临的最极端的竞争环境，在极端环境中提炼出的决策原则，放到商业、投资、生活中不仅适用，而且往往比现代理论更深刻——因为它经过了2500年的检验。

### 1.2 现代人最需要的三件事，兵法都给了

| 现代困境 | 兵法解答 |
|----------|----------|
| 信息过载，不知如何决策 | "庙算"——结构化评估框架 |
| 竞争激烈，资源有限 | "避实击虚"——找对手的弱点下手 |
| 行动焦虑，频繁出错 | "先胜后战"——等条件成熟再出手 |

### 1.3 股市投资者尤其需要

股市是最接近战场的现代场景：
- **零和博弈**（你赚的就是我亏的，总和为零）（散户之间）、**信息不对称**、**情绪对抗**、**资源不对等**
- 每一条兵法原则几乎都能直接对应一条交易原则
- 历史上最成功的交易者（利弗莫尔、索罗斯）的思想与孙子高度共鸣

## 四、学习方法论

### 4.1 三遍学习法

| 遍次 | 目标 | 方法 |
|------|------|------|
| 第一遍 | 通读，建立整体印象 | 快速读完所有材料，不求甚解，标记看不懂的地方 |
| 第二遍 | 精读，理解每篇原理 | 逐篇细读，做笔记，尝试用自己的话复述 |
| 第三遍 | 实践，对照真实场景 | 拿自己过往的决策/交易对照兵法原则，找出违背之处 |

### 4.2 一三一练习法

每学一篇，完成以下练习：

```
1条原文金句 → 用自己的话复述
3个应用场景 → 分别对应职场、生活、股市
1个自我反思 → "我过去哪个决策违背了这条原则？"
```

### 4.3 费曼检验法

判断你是否真正学会的方法：**能否用大白话向一个完全不懂的人讲清楚？**

- 讲不清楚 → 还没真懂
- 对方听不懂 → 你自己也没理解透
- 对方说"我懂了"并且能举一反例 → 过关

## 六·五、全系列术语速查表

学到后面会接触到不少股市术语，别慌——先看一眼这张表混个脸熟，遇到不懂的随时回来查。表里的"生活化比喻"是帮你快速理解，不是严谨定义。

| 术语 | 一句话解释 | 生活化比喻 | 首次出现 |
|------|-----------|-----------|---------|
| PE（市盈率） | 股价÷每股利润，衡量股票贵不贵 | 花多少年能靠利润回本 | 第四阶 |
| PB（市净率） | 股价÷每股净资产，衡量股价相对资产的高低 | 买二手车时车价 vs 车本身残值 | 第四阶 |
| ROE（净资产收益率） | 净利润÷净资产，衡量公司赚钱效率 | 一块钱本钱能生出几毛钱利润 | 第四阶 |
| 均线（MA） | 过去N天收盘价的平均值连成的线 | 把每天的体温连成线看发烧趋势 | 第四阶 |
| K线 | 用一根柱子表示一天开盘/收盘/最高/最低价的图 | 一根温度计，记录一天的冷热变化 | 第四阶 |
| 龙虎榜 | 当日异动股票的买卖前五席位公开名单 | 考试成绩单上"谁买了谁卖了"的前五名 | 第五阶 |
| 北向资金 | 从香港流入A股的资金，被视为"聪明钱" | 外校转来的尖子生，看他选什么课 | 第五阶 |
| 融资融券 | 借钱买股票 / 借股票先卖后买 | 借同学的钱买基金，或借同学的笔记先卖后买 | 第五阶 |
| 换手率 | 一天内股票转手买卖的比例 | 一个班今天有多少人换了座位 | 第四阶 |
| 止损 | 跌到预设价位就卖出，避免亏更多 | 玩游戏血量低于30%就撤退回城 | 第四阶 |
| 仓位 | 你投入股市的钱占总资金的比例 | 书包里有多少空间塞了课本 | 第四阶 |
| MACD | 一种判断趋势强弱的常用指标 | 温度计的变化速度，看升温还是降温 | 第五阶 |
| 布林带 | 用上下轨表示价格正常波动区间的指标 | 体温的正常波动范围，超出就是异常 | 第五阶 |
| 涨停 / 跌停 | 股价一天内涨/跌到规定的最大幅度停止交易 | 考试满分/零分，到顶就到顶 | 第四阶 |
| 散户 | 资金量小、个人买卖的普通投资者 | 街边小摊贩，跟大超市没法比 | 第一阶 |
| 主力 | 资金量大、能影响股价的大资金机构 | 大超市，进什么货能影响整条街 | 第一阶 |
| 大盘 | 整个股市的总体走势（如上证指数） | 全校平均分，反映整体水平 | 第一阶 |
| 蓝筹股 | 业绩稳定、规模大、有代表性的优质股票 | 班级里每次考试稳定前十的同学 | 第四阶 |

> **小贴士：** 看不懂术语不可怕，可怕的是不懂装懂。这张表你看一遍就行，等真正用到的时候再回来细看，那时会理解得更深。

## 七、核心信念

> 1. **兵法不是教你怎么打，而是教你怎么判断"该不该打"。**（打架之前先想想值不值得）
> 2. **最高境界不是百战百胜，而是不战而胜。**（最厉害的人不用动手就赢了）
> 3. **先胜后战——胜利在开打之前就已经决定了。**（真正决定胜负的是准备阶段，不是打的那一刻）
> 4. **知己比知彼更重要——大多数人亏钱不是败给市场，是败给自己。**（先搞清楚自己几斤几两，再去研究对手）
> 5. **兵法是思维框架，不是公式——理解原理比记住条文重要一百倍。**（别死记硬背，要搞懂为什么）
